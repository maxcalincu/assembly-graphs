**The Largest Assembly Number of an Assembly Graph with a Given Number of Vertices**

Репозиторий с материалами ВКР на тему «Наибольшее сборное число для сборного графа с заданным количеством вершин».


- [C++ библиотека](./library/core/README.md) в которой реализованы простые сборные графы, алгоритмы построения гамильтоновых множеств полигональных путей и несколько полезных тулов, использованных для валидации результатов ВКР.

- [Скрипт](./sag2svg.py) что создает изображение простого сборного графа по два-слову (см. [документацию](./docs/sag2svg.md)).

- [Описание](./patterns/README.md) анализа простых сборных графов без петель с наибольшим сборным числом путем работы с их паттернами.
