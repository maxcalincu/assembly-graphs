\section*{Аннотация}

Простым сборным графом называется конечный связный граф, в котором вершины имеют степени 1 или 4, для каждой вершины степени 4 задан циклический порядок инцидентных полурёбер, и граф обладает эйлеровым трансверсальным путём.
Сборным числом простого сборного графа называется минимальный размер его гамильтонова множества полигональных путей. Реализующим числом целого числа \(k\) называется наименьший размер графа, сборное число которого равно \(k\). Недавнее исследование показало, что известная верхняя оценка реализующего числа достигается на всех 
значениях \(k\): справедливо равенство 
\(\Rmin(k) = 3k - 2\), а множество графов 
с наибольшим сборным числом при заданном числе четырехвалентных вершин состоит в точности из петельных подстановок. Поскольку это семейство содержит 
много петель, в настоящей работе мы переносим внимание на семейство сборных графов без петель. Для этого более узкого класса получена точная формула аналога реализующего числа 
\(\Romin(k) = 5k - 3\). Полностью охарактеризованы экстремальные графы без петель для случая \(\D = 0\) (размер \(5k-3\)); 
с помощью компьютерного перебора, основанного на пересечении языков, порождённых недетерминированными конечнми автоматами, получено полное описание таких графов для случая \(\D = 1\) (размер \(5k-2\)).

\medskip
\noindent\textbf{Ключевые слова:} Сборное число, два-слово, простой сборный граф, реализующее число, полигональный путь, гамильтоново множество.

\section*{Abstract}

A simple assembly graph is a finite connected graph whose vertices have degrees 1 or 4; each 4‑valent vertex is endowed with a cyclic order of incident half-edges, and the graph admits an Eulerian transverse path.
The assembly number of a simple assembly graph is the minimum size of a Hamiltonian set of polygonal paths. 
The realization number of an integer \(k\) is the smallest size of a graph whose assembly number equals \(k\). 
A recent study showed that the well-known upper bound for the realization number is sharp for all \(k\): the equality \(\Rmin(k) = 3k-2\) holds, and the set of graphs maximizing the assembly number for a given number of 4‑valent vertices consists exactly of the loop‑saturated graphs. 
Since this family inherently contains numerous loops, the present work shifts attention to the family of loop‑free assembly graphs. For this narrower class, we obtain the exact formula for the analogue of the realization number, \(\Romin(k) = 5k-3\). 
Extremal loop‑free graphs are completely characterized for the case \(\D = 0\) (size \(5k-3\)); for the case \(\D = 1\) (size \(5k-2\)), a full description is obtained via an exhaustive computational search based on the intersection of languages generated by nondeterministic finite automata.

\medskip
\noindent\textbf{Keywords:} assembly number, double occurrence word, simple assembly graph, realization number, polygonal path, Hamiltonian set.

\section{Введение}

Понятие \emph{простого сборного графа} было введено в работе~\cite{Angeleska2009} в качестве математической модели процесса ДНК-рекомбинации у некоторых видов инфузорий. С комбинаторной точки зрения такой граф представляет собой конечный связный граф с вершинами степеней $1$ и $4$, причём в каждой вершине степени $4$ фиксирован циклический порядок инцидентных полурёбер, а сам граф обладает выделенным эйлеровым трансверсальным путём. Число $4$-валентных вершин называется \emph{размером} простого сборного графа $\Gamma$ и обозначается $|\Gamma|$.

Биологическая интерпретация состоит в том, что жёсткая вершина отвечает сайт-специфической рекомбинации, а отдельный ген, образующийся в результате рекомбинации, моделируется \emph{полигональным путём} — путём, который в каждой вершине «поворачивает», то есть проходит через неё по соседним в циклическом порядке полурёбрам. Множество генов, полученных из одной макромолекулы, даёт \emph{гамильтоново множество полигональных путей} — набор попарно не пересекающихся по вершинам полигональных путей, покрывающий все $4$-валентные вершины~\cite{Muche2012}. Минимальное количество путей среди всех таких наборов называется \emph{сборным числом} графа $\Gamma$ и обозначается $\An(\Gamma)$.

С каждым простым сборным графом естественно связано \emph{два-слово} — слово, в котором каждый символ некоторого алфавита встречается ровно дважды. Вершины графа отождествляются с различными буквами, а последовательные пары букв два-слова задают рёбра эйлерова трансверсального обхода, который однозначно определяет граф и циклические порядки в вершинах. Таким образом, изучение сборных графов сводится к анализу два-слов, что открывает возможности для применения методов теории графов, комбинаторики слов и теории формальных языков. Задача имеет глубокие связи с теорией узлов, виртуальных узлов и родов поверхностей~\cite{Kauffman1999,Cairns1996}.

Содержательно важными являются две экстремальные задачи:
\begin{itemize}
    \item Задача о \emph{реализующем числе} $\Rmin(k)$ — минимальном числе $4$-валентных вершин в простом сборном графе, имеющем сборное число $k$.
    \item Для заданного числа вершин $n$ найти максимально возможное значение $\An(\Gamma)$ и описать все графы, на которых этот максимум достигается.
\end{itemize}

В общем классе простых сборных графов эти задачи были полностью решены в недавней работе~\cite{MaksaevPreprint}. С помощью анализа жадного алгоритма, строящего малое гамильтоново множество полигональных путей, там было доказано, что $\Rmin(k)=3k-2$, а графами с наибольшим сборным числом при фиксированном размере оказались в точности \emph{петельные подстановки} (loop‑saturated graphs), введённые в~\cite{Muche2012}. Петельные подстановки неизбежно содержат большое количество петель, поэтому естественно поставить вопрос о том, как меняется реализующее число при переходе к семейству \emph{простых сборных графов без петель}. Соответствующее реализующее число мы обозначаем $\Romin(k)$.

В настоящей работе вводится подход, основанный на анализе \emph{паттернов} два-слов, симметричной версии жадного алгоритма и технике пересечения недетерминированных конечных автоматов. Получены следующие основные результаты:
\begin{itemize}
    \item Для любого простого сборного графа без петель справедливо неравенство $|\Gamma|\ge 5\cdot\An(\Gamma)-3$, откуда следует нижняя оценка $\Romin(k)\ge 5k-3$.
    \item Предъявлено семейство графов, на которых достигается равенство $|\Gamma|=5\cdot\An(\Gamma)-3$, а именно $(1212)$-подстановки; тем самым доказано, что $\Romin(k)=5k-3$.
    \item Дана полная комбинаторная характеризация экстремальных графов без петель: граф $\Gamma$ без петель удовлетворяет $|\Gamma|=5\cdot\An(\Gamma)-3$ тогда и только тогда, когда он является $(1212)$-подстановкой.
    \item Для остаточных значений $\D\equiv|\Gamma|+3\pmod{5},\; 1 \leq\D \leq 4$ дано описание графов без петель с максимальным сборным числом в рамках введённого языка.
    \item Дана полная комбинаторная характеризация экстремальных графов без петель размера $|\Gamma| = 5k - 2$ путём компьютерного перебора паттернов, удовлетворяющих автоматным ограничениям.
\end{itemize}

Работа организована следующим образом. В~разделе~\ref{sec:litrev} представлен обзор литературы, в котором прослеживается эволюция понятий сборного графа и сборного числа, обсуждаются ключевые концепции (петельные подстановки, аддитивность) и формулируется переход к случаю графов без петель. В~разделе~\ref{sec:term} собраны основные определения и обозначения, используемые в статье. В~разделе~\ref{sec:saturations} исследуются $w$-подстановки и их сборные числа. Раздел~\ref{sec:Romin} посвящён доказательству точной формулы реализующего числа для графов без петель $\Romin(k)=5k-3$. В~разделе~\ref{sec:max-an} получена полная характеризация графов без петель с наибольшим сборным числом при фиксированном размере; для остаточных значений $\D$ описание дано на языке регулярных выражений и пересечения конечных автоматов. Программная реализация алгоритмов пересечения конечных автоматов и тестирования сборных графов доступна в репозитории \url{https://github.com/maxcalincu/assembly-graphs}.

\section{Обзор литературы}\label{sec:litrev}

Теория сборных графов сформировалась на стыке математического моделирования внутриклеточных процессов и комбинаторики. Основополагающей работой является статья~\cite{Angeleska2009}, где впервые были введены понятия сборного графа и сборного числа, а также установлена их связь с процессами сайт-специфической ДНК-рекомбинации у инфузорий. В биологическом контексте макронуклеус простейших преобразуется путём удаления внутренних участков ДНК и перестановки оставшихся фрагментов; эти процессы моделируются сборными графами~\cite{Ehrenfeucht2005,Brijder2007}. В работе~\cite{Angeleska2009} была предложена конструкция, дающая верхнюю оценку реализующего числа $\Rmin(k)\le 3k-2$, и доказано существование графов со сколь угодно большим сборным числом.

Переход от графов к два-словам позволил применить мощный арсенал комбинаторики слов. Два-слова (double occurrence words), известные также как гауссовы слова, тесно связаны с диаграммами узлов и виртуальных узлов~\cite{Kauffman1999}, а также с плоскими кривыми и родами поверхностей~\cite{Cairns1996}. Изучению комбинаторных свойств классов два-слов посвящён ряд работ, среди которых отметим подсчёт неприводимых два-слов в~\cite{Burns2011} и описание простых сборных графов с наибольшим количеством различных гамильтоновых множеств полигональных путей в \cite{Guterman2026}.

Важным этапом развития теории стала работа~\cite{Muche2012}. В ней были введены понятия \emph{петельной подстановки} (loop‑saturated graph), при которой каждое ребро исходного графа заменяется петлёй. Было показано, что для петельной подстановки $\hat{\Gamma}$ выполняются равенства $\An(\hat{\Gamma})=|\Gamma|+1$ и $|\hat{\Gamma}|=3\An(\hat{\Gamma})-2$, что дало альтернативное доказательство оценки $\Rmin(k)\le 3k-2$. Кроме того, в~\cite{Muche2012} исследованы свойства аддитивности: лево-, право- и двусторонне аддитивные слова, поведение которых при композиции с другими графами позволяет контролировать сборное число. Эти конструкции и понятия легли в основу дальнейших исследований.

Недавний препринт~\cite{MaksaevPreprint} полностью закрыл вопрос о реализующем числе в общем классе простых сборных графов. В нём был разработан жадный алгоритм $\mathcal{G}$, который по любому сборному графу строит гамильтоново множество полигональных путей малого размера. Тщательный анализ работы этого алгоритма позволил доказать нижнюю оценку $\Rmin(k)\ge 3k-2$ и установить, что равенство $|\Gamma|=3\An(\Gamma)-2$ достигается в точности на графах петельных подстановок. Тем самым было получено точное значение $\Rmin(k)=3k-2$ и полная характеризация экстремальных графов. 

Существенно, что петельные подстановки содержат много петель, что делает естественным изучение аналога реализующего числа в классе простых сборных графов без петель — $\Romin(k)$. Прямой перенос методов из статьи~\cite{MaksaevPreprint} на этот случай невозможен, поскольку оценки жадного алгоритма становятся значительно слабее, а структура экстремальных графов оказывается более сложной.

Класс простых сборных графов без петель изучается впервые. Для его анализа в настоящей работе применяется техника, не использованная ранее в этом контексте: симметризация жадного алгоритма, переход к паттернам два-слов и использование пересечения недетерминированных конечных автоматов. Это позволило не только установить точное значение $\Romin(k)=5k-3$, но и дать исчерпывающее комбинаторное описание графов, на которых достигается максимальное сборное число в беспетельном семействе.

\section{Терминология и обозначения}\label{sec:term}

Мы придерживаемся обозначений и определений, введённых в~\cite{Angeleska2009,Muche2012,MaksaevPreprint}. В этой статье мы рассматриваем конечные связные неориентированные графы с вершинами степени 1 или 4. Петли и кратные рёбра допускаются. Для такого графа $\Gamma$ через $V(\Gamma)$ и $E(\Gamma)$ обозначаются множества вершин и рёбер между двумя 4-валентными вершинами графа $\Gamma$ соответственно. Повсюду в тексте под степенью вершины понимается число полурёбер, то есть частей рёбер в локальной окрестности вершины, инцидентных этой вершине; при этом все кратные рёбра считаются по отдельности, а каждая петля считается дважды. Точнее говоря, если существует петля, инцидентная $v \in V(\Gamma)$, то она представляется двумя полурёбрами, добавляя тем самым два к степени $v$.

Для набора полурёбер $(e_1, e_2, e_3, e_4)$ мы определяем его \emph{циклический порядок} как следующее множество, состоящее из всех его циклических сдвигов и их обращений:
\begin{equation*}
\begin{aligned}
(e_1, e_2, e_3, e_4)_{\text{cyc}} = \{&(e_1, e_2, e_3, e_4),\,
(e_2, e_3, e_4, e_1),\,
(e_3, e_4, e_1, e_2),\,
(e_4, e_1, e_2, e_3),\\
&(e_4, e_3, e_2, e_1),\,
(e_3, e_2, e_1, e_4),\,
(e_2, e_1, e_4, e_3),\,
(e_1, e_4, e_3, e_2)\}.
\end{aligned}
\end{equation*}
Иными словами, мы считаем все элементы множества $(e_1, e_2, e_3, e_4)_{\text{cyc}}$ эквивалентными и обычно ссылаемся на один элемент этого порядка. Мы говорим, что вершина $v \in V(\Gamma)$ степени 4 является \emph{регулярной}, если циклический порядок полурёбер, инцидентных этой вершине, зафиксирован (вообще говоря, есть всего три способа сделать это). Повсюду в тексте мы изображаем графы как локально вложенные в поверхность в каждой вершине. Каждая вершина $v$ рассматривается как маленький диск, так что инцидентные рёбра прикреплены к границе диска. Циклический порядок полурёбер обычно задаётся так, как мы считываем их на диаграмме, следуя границе диска.

Предположим, что для вершины \( v \) степени 4 задан следующий циклический порядок полурёбер: \((e_1, e_2, e_3, e_4)\). Тогда мы говорим, что \( e_1 \) и \( e_2 \) являются \emph{соседними в \( v \)}, также как \( e_2 \) и \( e_3 \), \( e_3 \) и \( e_4 \), а также \( e_4 \) и \( e_1 \). Заметим, что полурёбра петли также могут быть соседними. Мы говорим, что \( e_1 \) и \( e_3 \), а также \( e_2 \) и \( e_4 \) являются \emph{трансверсальными в \( v \)}. Пара рёбер, инцидентных \( v \), является трансверсальной тогда и только тогда, когда рёбра не являются соседними.

\emph{Сборный граф} — это конечный неориентированный связный граф, в котором все вершины имеют степень 1 или 4, и все вершины степени 4 являются \emph{регулярными}. Вершину степени 1 будем называть \emph{концевой вершиной}.

\emph{Путь} в графе — это чередующаяся последовательность вершин и рёбер, которая начинается и заканчивается вершиной, причём рёбра в этой последовательности инцидентны вершинам, стоящим рядом с ними. Если путь не содержит рёбер, то есть состоит из единственной вершины, он называется \emph{синглтоном} или путем нулевой длины. Под длиной пути мы будем понимать число рёбер в нём.

\begin{definition}[\cite{Angeleska2009}, Определение 3.3] \emph{Трансверсальный путь} в сборном графе, или просто \emph{трансверсаль}, — это путь \( v_0 e_1 v_1 e_2 \cdots e_n v_n \), удовлетворяющий следующим условиям:

\begin{itemize}
    \item $v_0$ и $v_n$ --- четырехвалентные вершины смежные с концевыми вершинами графа.
    \item Все рёбра \( e_1, \ldots, e_n \) попарно различны.
    \item Каждое ребро \( e_i \) не является соседним с \( e_{i-1} \) в регулярной вершине \( v_{i-1} \) (\( i = 2, \ldots, n \)). Когда \( e_i \) является петлёй (\( v_{i-1} = v_i \)), оба полурёбра \( e_i \) помечаются как \( e_i^{(1)} \) и \( e_i^{(2)} \) таким образом, что \( e_{i-1} \) и \( e_i^{(1)} \) не являются соседними в \( v_i \), а также \( e_i^{(2)} \) и \( e_{i+1} \) не являются соседними.
\end{itemize}

\end{definition} 

Пример трансверсального пути можно видеть на рисунке \ref{fig:transversal_path}. Заметим, что в вершине \( v_1 \) трансверсальный путь сначала идёт по «правому» полурёбру, соответствующему петле \( e_1 \), а затем проходит через «левое» полурёбро петли \( e_1 \). В то же время в вершине \( v_3 \) путь сначала идёт по «левому» полурёбру петли \( e_4 \), а затем проходит через её «правое» полурёбро.

О сборном графе удобно думать как о \emph{семействе замкнутых гладких кривых} в трёхмерном пространстве с
$n$ различными точками, в которых две кривые (не обязательно различные) пересекаются по разным направлениям. Все такие точки пересечения соответствуют 4-валентным вершинам графа, а дуги кривых, соединяющие эти точки, — рёбрам. В этой геометрической модели два полурёбра являются соседними, если их направления касательных в точке пересечения различны, а трансверсальный путь — это просто гладкая кривая.

Два трансверсальных пути эквивалентны, если они совпадают. \emph{Простым сборным графом} называется сборный граф, обладающий эйлеровым трансверсальным путём, то есть трансверсальным путём, проходящим по каждому ребру ровно один раз. Заметим, что в простом сборном графе есть лишь два класса эквивалентности трансверсальных эйлеровых путей, которые отличаются обращением (см. \cite[Лемма 3.6]{Angeleska2009}). У простого сборного графа зафиксирована ориентация: одну из концевых вершин мы будем называть начальной, вторую — финальной. Мы говорим, что два графа \emph{изоморфны как простые сборные графы}, если существует изоморфизм графов между ними, который переводит начальную вершину одного графа в начальную вершину другого и продолжается до биекции на полурёбрах, сохраняющей их циклический порядок во всех регулярных вершинах. Это означает, что простые сборные графы однозначно определяются трансверсальным эйлеровым путём (см. \cite[Определение 3.2 и Лемма 3.7]{Angeleska2009}).

Путь \( v_0e_1v_1 \cdots v_{\ell-1}e_\ell v_\ell \) в сборном графе называется \emph{полигональным} (см. \cite[Раздел 2]{Muche2012}), если все вершины \( v_0, \ldots, v_\ell \) являются попарно различными вершинами степени 4 графа \( \Gamma \), а \( e_i \) и \( e_{i+1} \) являются соседними в \( v_i \) для всех \( i = 1, \ldots, \ell - 1 \). Заметим, что цикл (в частности, петля) не является полигональным путём, поскольку все вершины в нём должны быть различны, в то время как изолированная вершина представляет собой полигональный путь. Примеры полигональных путей представлены на рисунке \ref{fig:hamiltonian_set_of_polygonal_paths}.

Неформально, если рассматривать вершину как перекрёсток, проходя через регулярную вершину, полигональный путь либо поворачивает налево, либо направо. С другой стороны, трансверсальный путь на каждом перекрестке следует \emph{прямо}.

Два пути \emph{не пересекаются по вершинам}, если они не имеют общих вершин. Множество попарно не пересекающихся по вершинам полигональных путей в сборном графе \( \Gamma \) называется \emph{гамильтоновым}, если его объединение покрывает все вершины степени 4 графа \( \Gamma \) (см. рисунок \ref{fig:hamiltonian_set_of_polygonal_paths}).

Пусть $\gamma$ — гамильтоново множество полигональных путей в простом сборном графе $\Gamma$. Через $E(\gamma)$ мы обозначаем множество рёбер, задействованных в полигональных путях. Заметим, что по $E(\gamma)$ можно однозначно восстановить $\gamma$. В частности, $E(\gamma) = \emptyset$ соответствует $\gamma$, покрывающему каждую 4-валентную вершину синглтоном.

\begin{lemma}[\cite{MaksaevPreprint}]\label{lemma:edge-setsize-rel}
    Пусть $\gamma = \{\gamma_1, \gamma_2, \dots,\gamma_t\}$ — некоторое гамильтоново множество полигональных путей некоторого простого сборного графа $\Gamma$. Тогда $E(\gamma) = \bigcup_i\gamma_i$ — множество рёбер путей из $\gamma$.
    \[
    |\Gamma| = |E(\gamma)| + |\gamma|
    \]
\end{lemma}

\begin{proof}
    Полигональные пути формируют лес в графе, индуцированном $E(\gamma)$. Для леса это утверждение хорошо известно.
\end{proof}

Пусть $\Sigma=\{a_1,a_2,\ldots\}$ — конечный алфавит. Слово $w=w_1w_2\ldots w_{2n}$ из $2n$ букв в алфавите $\Sigma$ называется \emph{два-словом} или сборным словом (double occurrence word, DOW), если каждая буква из $\Sigma$ встречается в нём ровно два раза. Число $n=|w|$ называют длиной два-слова. В литературе что касается теории плоских кривых также встречается термин \emph{гауссовых слов} для обозначения этой концепции. 

Сборные слова называются \textit{эквивалентными}, если одно из другого можно получить переименованием символов алфавита. Существует взаимно-однозначное соответствие между классами изоморфизма простых сборных графов и классами эквивалентности два-слов, как доказано в \cite[Лемма 3.8]{Angeleska2009}. Ниже мы кратко приводим эту конструкцию для полноты и дальнейшего использования.

Перечисление вершин степени 4, посещаемых трансверсальным путём в простом сборном графе, даёт два-слово над алфавитом \(V(\Gamma)\), поскольку любой трансверсальный путь должен посетить каждую вершину степени 4 дважды. Следовательно, сборные слова эквивалентны тогда и только тогда, когда они соответствуют изоморфным сборным графам.

Для простого сборного графа \(\Gamma\) обозначим представителя соответствующего класса сборных слов через \(w_\Gamma\). Обратно, \emph{простой сборный граф} $\Gamma_w$, ассоциированный с два-словом $w$, строится следующим образом.
\begin{itemize}
    \item Множество вершин $V(\Gamma_w)$ состоит из всех различных букв слова $w$; все эти вершины считаются $4$-валентными.
    \item Рёбра графа отвечают последовательным парам букв слова: для каждого $i=1,\dots,2n-1$ вводится ребро $e_i=(w_i,w_{i+1})$.
    \item Циклический порядок полурёбер в каждой вершине задаётся порядком обхода вдоль слова $w$ (эйлеров трансверсальный путь). Иными словами, в локальной окрестности вершины полурёбра упорядочены так, как они появляются при движении от первого вхождения буквы ко второму и далее к концу слова.
    \item В слово дополнительно включают два фиктивных концевых символа, дающих начало и конец трансверсального пути; соответствующие им вершины имеют степень $1$ и называются \emph{концевыми}.
\end{itemize}
Граф $\Gamma_w$ является связным, все его $4$-валентные вершины \emph{регулярны}, а концевые вершины имеют степень $1$.

\emph{Реализующим числом} $\Rmin(k)$ называется минимальное количество $4$-валентных вершин в простом сборном графе, сборное число которого равно $k$:
\[
\Rmin(k)=\min\{\,|\Gamma|:\An(\Gamma)=k\,\}.
\]
Аналогично, $\Romin(k)$ обозначает реализующее число в классе простых сборных графов без петель.

Пусть $w$ и $u$ — два два-слова без общих букв. Их \emph{композицией} $w\circ u$ называется конкатенация $wu$. Композиция простых сборных графов $\Gamma_w$ и $\Gamma_u$ обозначается как $\Gamma_w \circ \Gamma_u$ и соответствует два-слову композиции $w\circ u$.

\begin{definition}[{\cite[Definition 2.3.1]{Muche2012}}]
    Простой сборный граф $\Gamma$ называется \emph{аддитивным слева}, если для любого простого сборного графа $\Gamma'$ выполнено
    \[
        \An(\Gamma \circ \Gamma') = \An(\Gamma) + \An(\Gamma').
    \]
    Аналогично, $\Gamma$ называется \emph{аддитивным справа}, если для любого $\Gamma'$ выполнено
    \[
        \An(\Gamma' \circ \Gamma) = \An(\Gamma') + \An(\Gamma).
    \]
    Граф, являющийся одновременно аддитивным слева и справа, называется \emph{аддитивным}.

    Простой сборный граф $\Gamma$ называется \emph{двусторонне аддитивным}, если для любых сборных графов $\Gamma_1,\Gamma_2$ справедливо
    \[
        \An(\Gamma_1 \circ \Gamma \circ \Gamma_2) =
        \An(\Gamma_1) + \An(\Gamma) + \An(\Gamma_2).
    \]
\end{definition}

\begin{lemma}[{\cite[Лемма 2.3.6]{Muche2012}}]\label{lem:additivity-criterion}
    Пусть $\Gamma$ — простой сборный граф, а $\Gamma_{(1)}$ — граф петли, соответствующий два-слову $(11)$. Тогда
    \begin{enumerate}
        \item $\Gamma$ аддитивен справа $\iff$ $\An(\Gamma_{(1)} \circ \Gamma) = \An(\Gamma) + 1$;
        \item $\Gamma$ аддитивен слева $\iff$ $\An(\Gamma \circ \Gamma_{(1)}) = \An(\Gamma) + 1$;
        \item $\Gamma$ двусторонне аддитивен $\iff$ $\An(\Gamma_{(1)} \circ \Gamma \circ \Gamma_{(1)}) = \An(\Gamma) + 2$.
    \end{enumerate}
\end{lemma}

Всякий двусторонне аддитивный граф является аддитивным, но не наоборот. Граф аддитивен, но не двусторонне аддитивен, когда справедливо:

\begin{enumerate}
    \item $\An(\Gamma_{(1)} \circ \Gamma) = \An(\Gamma) + 1$;
    \item $\An(\Gamma \circ \Gamma_{(1)}) = \An(\Gamma) + 1$;
    \item $\An(\Gamma_{(1)} \circ \Gamma \circ \Gamma_{(1)}) = \An(\Gamma) + 1$.
\end{enumerate}

Мы называем граф \emph{неаддитивным}, если хотя бы одно условие аддитивности для него нарушается: $\An(\Gamma_{(1)} \circ \Gamma) = \An(\Gamma)$ либо $\An(\Gamma \circ \Gamma_{(1)}) = \An(\Gamma)$.

\begin{definition}
	\emph{Петельной подстановкой} $\hGamma$ простого сборного графа $\Gamma$ называется граф, полученный заменой каждого ребра графа $\Gamma$ петлёй. 
    
    Пусть $g = g_1, ..., g_{2n}$ --- два-слово изначального графа, а $h_1,h_2,...,h_{2n+1}$ --- различные символы что не встречаются в слове $g$. Два-слово петельной подстановки имеет следующий вид.

    \[
    h_1,h_1,g_1,h_2,h_2,g_2,...,g_{2n},h_{2n + 1},h_{2n + 1}
    \]
\end{definition}

\begin{definition}[\cite{MaksaevPreprint}]
    Пусть $\Gamma$ --- простой сборный граф, где $e_1,e_2,\ldots,e_{2n - 1}$ его рёбра в порядке трансверсального обхода. Обозначим через $\G$ итеративный алгоритм, который по $\Gamma$ строит гамильтоново множество полигональных путей следующим образом:
   
    \begin{itemize}
        \item Начинаем с тривиального множества $\gamma$, $E(\gamma) = \emptyset$.
        \item На $i$-м шаге обрабатываем ребро $e_i$. Добавляем ребро $e_i$ в $E(\gamma)$, если итоговое множество ребер всё ещё задаёт корректное гамильтоново множество полигональных путей. 
    \end{itemize}
\end{definition}

\begin{definition}
    Пусть буква $x$ появляется в два-слове $w = w_1,\ldots,w_{2n}$ на позициях $j_1$ и $j_2$, где $j_1 < j_2$. Будем говорить, что $w_{j_1}$ является \emph{первым} вхождением $x$, а $w_{j_2}$ \emph{вторым} вхождением $x$. 
\end{definition}

Наряду с графом $\Gamma$ мы часто рассматриваем обращённый граф $\Gamma^R$, соответствующий два-слову, прочитанному в обратном порядке. Сборное число при обращении не меняется: $\An(\Gamma)=\An(\Gamma^R)$.

Подобно множеству задач из теории графов, мы будем называть процесс добавления ребра в $E(\gamma)$ \emph{закраской} ребра. 

\section{Подстановки}\label{sec:saturations}

Для изучения простых сборных графов без петель нам понадобится обобщить понятие петельной подстановки.

\begin{definition}
     Сборный граф $\mathcal{S}_w(\Gamma)$, полученный из данного сборного графа $\Gamma$ и непустого два-слова $w$ путём замены всех рёбер графа $\Gamma$ на копии графа $\Gamma_{w}$, будем называть \textit{сборным графом, полученным из $\Gamma$ путём $w$-подстановки}.

     Сборный граф $\mathcal{S}^{\circ}_w(\Gamma)$, полученный из данного сборного графа $\Gamma$ и два-слова $w$ путём замены всех рёбер графа $\Gamma$ на копии графа $\Gamma_{w}$, кроме рёбер, инцидентных концевым вершинам, будем называть \textit{сборным графом, полученным из $\Gamma$ путём внутренней $w$-подстановки}.
\end{definition}

Таким образом, определения петельной подстановки $\hGamma$ и внутренней петельной подстановки $\hGamma^\circ$ из \cite{Muche2012} совпадают с $\mathcal{S}_{(11)}(\Gamma)$ и $\mathcal{S}^{\circ}_{(11)}(\Gamma)$.

Аналогично \cite{MaksaevPreprint}, мы отождествляем гамильтоново множество полигональных путей $\gamma$ с множеством рёбер $E(\gamma)$, которые в него входят. Часто мы не будем различать задачу минимизации числа полигональных путей и задачу максимизации числа рёбер в них, так как, уже было сказано ранее, они связаны линейным уравнением.
\[
    |\Gamma| = |\gamma| + |E(\gamma)|
\]
Чтобы проверить, что какое-то подмножество рёбер $E' \subset E(\Gamma)$ задаёт корректное гамильтоново множество полигональных путей, нужно проверить два условия.
\begin{itemize}
    \item \emph{Полигональность} — никакие два последовательных ребра трансверсального пути одновременно не находятся в $E'$. 
    \item \emph{Отсутствие циклов} — в графе ограничения $\Gamma$ на $E'$ нет циклов. 
\end{itemize}

Пусть дано слово $w$ длины $m$ и простой сборный граф $\Gamma$ с $n$ 4-валентными вершинами, которому соответствует два-слово $g$. Тогда графу $\check{\Gamma} = \mathcal{S}_w(\Gamma)$ соответствует слово:
\[
w^1,g_1,w^2,g_2,\dots,w^{2n},g_{2n},w^{2n + 1}
\]
где $\{w^i\}_{i = 1}^{2n + 1}$ — копии слова $w$, а $\{g_i\}_{i = 1}^{2n}$ — буквы слова $g$. 
Введём обозначения для следующих подмножеств рёбер.

\begin{enumerate}
    \item $E_{w^i}$ — внутренние рёбра $w^i$.
    \[
        E_{w^i}= \{e \in E(\check{\Gamma}) : V(e) \subset V(w^i)\}
    \]
    \item $E_{g}$ — рёбра, связывающие копии $w$ с исходными вершинами $g$.
    \[
        E_{g} = \{e \in E(\check{\Gamma}): \exists g_i \in V(e)\}. 
    \]
\end{enumerate}

Заметим, что каждое ребро $\check{\Gamma}$ попало ровно в одно подмножество:  $E(\check{\Gamma}) = (\bigsqcup_{i=1}^{2n + 1} E_{w^i}) \sqcup E_g$.

\begin{theorem}\label{theor:an-saturation} 
    Для любого простого сборного графа $\Gamma$ и любого непустого два-слова $w$ верны неравенства:
    
    \begin{enumerate}
        \item $\An(\mathcal{S}_w(\Gamma)) \leq (2|\Gamma| + 1)\cdot\An(w) + |\Gamma|$
        \item $\An(\mathcal{S}_w(\Gamma)) \geq (2|\Gamma| + 1)\cdot\An(w) - |\Gamma| $.
    \end{enumerate}
\end{theorem}

\begin{proof}
    Докажем каждое неравенство по отдельности.

    \begin{enumerate} 
        \item Пусть $\gamma_w$ будет некоторым минимальным гамильтоновым множеством полигональных путей для $w$. Множество $\gamma_w$ индуцирует покраску рёбер всякого $w^i$. В совокупности это задаёт корректное гамильтоново множество полигональных путей $\gamma$ для $\check{\Gamma}$. 
        \[ 
        E(\gamma) \cap E_{w^i} \sim E(\gamma_w) \quad \forall i 
        \]
        Полигональность выполняется по построению. Граф $\check{\Gamma}$, ограниченный на $E(\gamma)$, разбивается на $2n + 1$ подграфов, изоморфных графу $\Gamma_w$, ограниченному на $E(\gamma_w)$. Ни в одном из них циклов нет, а значит $\gamma$ — корректно. Итого $\An(\check{\Gamma}) \leq |\gamma| = (2|\Gamma| + 1) \cdot \An(w) + |\Gamma|$

        \item В силу полигональности не больше $2n$ рёбер из $E_g$ единовременно могут быть покрашены. С другой стороны, покраска любого $w^i$ должна задавать корректную покраску $w$. 

        \[
        |E(\gamma)| = \sum_i|E(\gamma)\cap E_{w^i}| + |E(\gamma) \cap E_g| \leq (2n + 1)(m - \An(w)) + 2n
        \]
        
        Отсюда получаем $\An(\check{\Gamma}) = |\check{\Gamma}| - |E(\gamma)| \geq (2n + 1)\cdot \An(w) - n$

    \end{enumerate}
\end{proof}

Сборное число $w$-подстановки тесно связано с понятиями аддитивности и двусторонней аддитивности. 

\begin{lemma}\label{lemma:left-additive}
    Простой сборный граф $\Gamma$ является аддитивным слева тогда и только тогда, когда не существует минимального гамильтонова множества полигональных путей такого, что заключительное ребро его трансверсального пути не закрашено.
\end{lemma}

\begin{proof}
    Как уже было сказано ранее, простой сборный граф $\Gamma$ является аддитивным слева, если $\An(\Gamma\circ \Gamma_{(1)}) = \An(\Gamma) + 1$. Закрашивать петлю $\Gamma_{(1)}$ нельзя, так как это создаст цикл. Пусть $e$ — ребро, соединяющее $\Gamma$ с петлей $\Gamma_{(1)}$. Пусть $\gamma$ — минимальное гамильтоново множество полигональных путей для графа $\Gamma\circ \Gamma_{(1)}$. Разберём два случая.

    \begin{itemize}
        \item Ребро $e$ не закрашено. В таком случае $E(\gamma)$ задаёт корректное гамильтоново множество полигональных путей для $\Gamma$. Следовательно, $\An(\Gamma\circ\Gamma_{(1)}) = |\Gamma| - |E(\gamma)| + 1 = \An(\Gamma) + 1$.
        \item Ребро $e$ закрашено. В таком случае $E(\gamma) \setminus \{e\}$ задаёт корректное гамильтоново множество полигональных путей для $\Gamma$ (назовём его $\gamma'$). Причём, в силу полигональности, заключительное ребро трансверсального пути $\Gamma$ у $\gamma'$ не закрашено. Нам интересен лишь случай $|E(\gamma)\setminus \{e\}| = |\Gamma| - \An(\Gamma)$, поскольку в противном случае мы получаем множество полигональных путей не лучше, чем если бы не закрашивали $e$. Если $E(\gamma) - 1 = |\Gamma| - \An(\Gamma)$, мы получаем $\An(\Gamma\circ\Gamma_{(1)}) = |\Gamma| - |E(\gamma)| + 1 = \An(\Gamma)$.
    \end{itemize}

    Если у исходного графа $\Gamma$ существует минимальное гамильтоново множество полигональных путей $\gamma$, которое не закрашивает последнее ребро трансверсального пути, то $E(\gamma) \cup \{e\}$ задаёт корректное гамильтоново множество полигональных путей для $\Gamma\circ \Gamma_{(1)}$ размера $\An(\Gamma)$. Из рассуждения выше понятно, что меньше множества найти нельзя. В противном случае, как и было заявлено, сборное число $\An(\Gamma\circ \Gamma_{(1)}) = \An(\Gamma) + 1$.
\end{proof}

\begin{lemma}\label{lemma:middle-additive}
    Простой аддитивный сборный граф $\Gamma$ является двусторонне аддитивным тогда и только тогда, когда не существует гамильтонова множества полигональных путей размера $\An(\Gamma) + 1$ такого, что первое и заключительное ребро его трансверсального пути одновременно не закрашены.
\end{lemma}

\begin{proof}
    Доказательство полностью аналогично рассуждению из леммы \ref{lemma:left-additive}.
\end{proof}

\begin{conjecture}\label{conj:an-additive-saturation}
    Пусть дан простой сборный граф $\Gamma$ и непустое неаддитивное два-слово $w$. Тогда сборное число $w$-подстановки имеет следующий вид.
    \[
        \An(\mathcal{S}_w(\Gamma)) = (2|\Gamma| + 1)\cdot\An(w) - |\Gamma|
    \]

\end{conjecture}

\begin{proof}
    Формулу достаточно доказать либо для $w$, либо для $w^R$, поскольку сборное число не меняется при обращении слова. Заметим, что аддитивность справа у $w$ эквивалентна аддитивности слева у $w^R$. Следовательно, неаддитивность $w$ означает, что либо $w$, либо $w^R$ не является аддитивным слева. Без ограничения общности будем считать, что аддитивность слева нарушена именно у $w$.
 
    У два-слова $w$ существует минимальное гамильтоново множество полигональных путей $\gamma_w$ с незакрашенным последним ребром трансверсального пути согласно лемме~\ref{lemma:left-additive}.
    Построим множество полигональных путей $\gamma$ для $\check{\Gamma}$ следующим образом.
    \begin{itemize}
        \item Покраска $w^i$ индуцирована множеством $E(\gamma_w)$.
        \[
            E(\gamma) \cap E_{w^i} \sim E(\gamma_w)
        \]
        \item Пусть рёбра $e_l^i, e_r^i$ соединяют вершину $g_i$ с $w^i$ и $w^{i + 1}$ соответственно. Закрасим все рёбра $\{e_l^i\}$.
    \end{itemize}

    Чтобы убедиться в корректности $\gamma$, нужно проверить два свойства.

    \begin{itemize}
        \item Полигональность выполняется по построению. Рёбра $\{e_l^i\}$ ни с чем не конфликтуют благодаря выбору $\gamma_w$. 
        \item Отсутствие циклов. Предположим противное: в $E(\gamma)$ есть цикл положительной длины. С одной стороны, цикл не может целиком содержаться ни в одной компоненте $w^i$ по построению. С другой стороны, цикл не может проходить положительное число раз через разрез, определяемый вершинами какой-либо компоненты $V(w^i)$, поскольку любой цикл обязан проходить через разрез чётное число раз, а множество $E(\gamma)$ пересекается с таким разрезом лишь по ребру $e^i_l$. Мы пришли к противоречию.
    \end{itemize} 
     Мы закрасили $2n$ рёбер из $E_g$ и $m - \An(w)$ рёбер из каждого $E_{w^i}$. Из доказательства второго пункта теоремы \ref{theor:an-saturation} понятно, что это максимальное количество рёбер, которое может быть закрашено в каждой из компонент. Следовательно, это минимальное гамильтоново множество полигональных путей.
    \[
    \An(\mathcal{S}_w(\Gamma)) = (2|\Gamma| + 1)\cdot\An(w) - |\Gamma|
    \]
\end{proof}

\begin{corollary}\label{cor:pretzelsat5k-3}
    Пусть $\Gamma$ простой сборный граф размера $k-1$.
    \begin{itemize}
        \item $(1212)$-подстановка графа $\Gamma$ имеет размер $5k - 3$ и сборное число $k$.
        \item $(11)$-подстановка (петельная подстановка) графа $\Gamma$  имеет размер $3k - 2$ и сборное число $k$.
    \end{itemize}
\end{corollary}

\begin{proof}
Действительно, два-слова $(1212)$ и $(11)$ являются неаддитивными:
\[
    \An(\Gamma_{(11)} \circ \Gamma_{(1212)}) = \An(\Gamma_{(1212)} \circ \Gamma_{(11)}) =\An(\Gamma_{(1212)}) = 1.
\]
\[
    \An(\Gamma_{(11)} \circ \Gamma_{(11)}) = \An(\Gamma_{(11)}) = 1.
\] 
А значит, из теоремы~\ref{conj:an-additive-saturation} следует, что $\An(\mathcal{S}_{(1212)}(\Gamma)) = \An(\mathcal{S}_{(11)}(\Gamma)) = (2\cdot |\Gamma| + 1) -|\Gamma| = |\Gamma| + 1 = k$. Размеры подстановок имеют следующий вид.

\[
    |\mathcal{S}_{(11)}(\Gamma)| = (2\cdot |\Gamma| + 1) \cdot 1 + |\Gamma| = 3\cdot |\Gamma| + 1 = 3k - 2.
\]
\[
    |\mathcal{S}_{(1212)}(\Gamma)| = (2\cdot |\Gamma| + 1) \cdot 2 + |\Gamma| = 5\cdot |\Gamma| + 2 = 5k - 3.
\]
\end{proof}

\begin{definition}
    Пусть $\Gamma$ — простой сборный граф. Определим функцию $\varphi_{i,j}(\Gamma),\; i,j \in \{0,1\}$ как максимальное количество закрашенных рёбер среди всех гамильтоновых множеств полигональных путей для $\Gamma$, таких что выполняются следующие условия.

    \begin{itemize}
        \item первое ребро трансверсального пути $\Gamma$ \emph{не закрашено}, если $i = 1$.
        \item последнее ребро трансверсального пути $\Gamma$ \emph{не закрашено}, если $j = 1$.
    \end{itemize}
\end{definition}

\begin{lemma}
    Пусть $\Gamma$ — аддитивный простой сборный граф.
    \begin{itemize}
        \item $\varphi_{0,0}(\Gamma) = |\Gamma| - \An(\Gamma)$
        \item $\varphi_{0,1}(\Gamma) = \varphi_{1,0}(\Gamma) = |\Gamma| - \An(\Gamma) - 1$
        \item $\varphi_{1,1}(\Gamma) = |\Gamma| - \An(\Gamma) - 2$ если $\Gamma$ — двусторонне аддитивный и $|\Gamma| - \An(\Gamma) - 1$ иначе.
    \end{itemize}
\end{lemma}

\begin{proof}
    Докажем каждый пункт по отдельности.
    \begin{itemize}
        \item Никаких ограничений нет. Следует напрямую из леммы \ref{lemma:edge-setsize-rel}.
        \item В силу симметрии, достаточно доказать утверждение лишь для $\varphi_{0,1}$. Оценку снизу $\varphi_{0,1}(\Gamma) \geq |\Gamma| - \An(\Gamma) - 1$ можно получить, взяв любое минимальное гамильтоново множество полигональных путей для $\Gamma$ и удалив из него последнее ребро трансверсального пути (если оно там есть). В худшем случае число рёбер уменьшится на единицу. Чтобы получить оценку сверху, предположим обратное: существует минимальное гамильтоново множество полигональных путей $\gamma$ для $\Gamma$, у которого не закрашено последнее ребро. Из леммы \ref{lemma:left-additive} следует, что $\Gamma$ не является аддитивным слева. Противоречие.
        \item Оценку снизу $\varphi_{1,1}(\Gamma) \geq |\Gamma| - \An(\Gamma) - 2$ можно получить способом, аналогичным предыдущему пункту. Эта функция накладывает больше ограничений, чем все предыдущие, а значит $\varphi_{1,1}(\Gamma) \leq \varphi_{0,1}(\Gamma) = |\Gamma| - \An(\Gamma) - 1$. Из леммы \ref{lemma:middle-additive} непосредственно следует, что $\varphi_{1,1}(\Gamma) = |\Gamma| - \An(\Gamma) - 2$ исключительно для двусторонне аддитивных простых сборных графов. 
    \end{itemize}
\end{proof}

\begin{conjecture}
    Для любого простого сборного графа $\Gamma$ и двусторонне аддитивного два-слова $w$:
    \[\An(\mathcal{S}_w(\Gamma)) = (2|\Gamma| + 1) \cdot \An(w) + |\Gamma|\].
\end{conjecture}
\begin{proof}
    Рассмотрим рёбра из следующего отрезка трансверсального пути $\Gamma$.
    \[
        g_i, w^i, g_{i + 1}
    \]
    Для полноты изложения будем считать, что $g_0$ и $g_{2n + 1}$ равны каким-то фиктивным символам. Помимо рёбер из $E_{w^i}$ в таком блоке участвуют рёбра $e_i^r$ и $e_{i + 1}^l$. Максимальное количество рёбер блока, которое можно одновременно закрасить, не больше $\varphi_{0,0}(w), \varphi_{1,0}(w) + 1, \varphi_{0,1}(w) + 1$ либо $\varphi_{1,1}(w) + 2$ в зависимости от того, покрашены рёбра $e_i^r, e_{i + 1}^l$ или нет. Заметим, что для двусторонне аддитивных слов все эти четыре функции равны $|w| - \An(w)$. Столько рёбер всегда можно покрасить, не задействуя рёбра $e_i^r$ и $e_{i + 1}^l$. Следовательно, для таких подстановок гамильтоново множество полигональных путей, описанное в первом пункте теоремы \ref{theor:an-saturation}, является минимальным.
\end{proof}

\begin{conjecture}
    Для любого простого сборного графа $\Gamma$ и аддитивного, но не двусторонне аддитивного два-слова $w$:
    \begin{itemize}
        \item $\An(\mathcal{S}_w(\Gamma)) = (2|\Gamma| + 1) \cdot \An(w) + \An(\Gamma)$ если $\An(\mathcal{S}_w^\circ(\Gamma_{(11)})) = \An(w) + 1$;
        \item $\An(\mathcal{S}_w(\Gamma)) = (2|\Gamma| + 1) \cdot \An(w)$ если $\An(\mathcal{S}_w^\circ(\Gamma_{(11)})) = \An(w)$.
    \end{itemize}
\end{conjecture}

\begin{proof}
    Пусть $\gamma$ — минимальное гамильтоново множество полигональных путей для $\mathcal{S}_w(\Gamma)$. Аналогично предыдущему рассуждению, разобьём трансверсальный путь на следующие блоки.
    \[
        g_i, w^i, g_{i + 1}
    \]
    Максимальное количество рёбер блока, которое можно одновременно закрасить, не больше $\varphi_{0,0}(w), \varphi_{1,0}(w) + 1, \varphi_{0,1}(w) + 1$ либо $\varphi_{1,1}(w) + 2$ в зависимости от того, покрашены рёбра $e_i^r, e_{i + 1}^l$ или нет. Для аддитивных, но не двусторонне аддитивных слов $w$ справедливо: $\varphi_{0,0}(w) = \varphi_{1,0}(w) + 1 = \varphi_{0,1}(w) + 1 = |w| - \An(w)$, в то время как $\varphi_{1,1}(w) +2= |w| - \An(w) + 1$. Как говорилось ранее, $|w| - \An(w)$ является базовым минимумом. Его можно достичь, не закрашивая рёбра $e_i^r$ и $e_{i + 1}^l$. Без ограничения общности будем считать, что $e_i^r$ и $e_{i + 1}^l$ одновременно либо закрашены, либо не закрашены. Пусть $S$ — множество блоков, у которых закрашены одновременно $e_i^r$ и $e_{i + 1}^l$. Каждому блоку из $S$ биективно соответствуют два закрашенных ребра из $E_g$. Отсюда получаем оценку $2\cdot|S| \leq |E_g\cap E(\gamma)| \leq 2n$. Это даёт оценку снизу на сборное число.
    \[
        \An(\mathcal{S}_w(\Gamma)) \geq (2|\Gamma| + 1) \cdot \An(w)
    \]
    Перейдём к разбору случаев.
    \begin{itemize}
        \item Пусть существует гамильтоново множество полигональных путей $\gamma_w$ для $w$ размера $|w| - \An(w) - 1$, такое что первое и последнее ребро трансверсального пути не закрашены и первая и последняя вершина трансверсального пути не соединены одним полигональным путём. Это означает, что для графа внутренней петельной подстановки $\mathcal{S}_w^\circ(\Gamma_{(11)})$ можно закрасить $\varphi_{11}(w)$ рёбер подграфа, изоморфного $w$, а также первое и последнее ребро трансверсального пути. Эта конструкция корректна и оптимальна. Следовательно, $\An(\mathcal{S}_w^\circ(\Gamma_{(11)})) = \An(w)$.

        Построим гамильтоново множество полигональных путей $\gamma$ для $\mathcal{S}_w(\Gamma)$ следующим образом.
        \begin{itemize}
            \item Покраска $w^i$ индуцирована множеством $E(\gamma_w)$.
            \item Красим $e_r^i$ и $e_l^{i + 1}$ для всех нечётных $i$.
        \end{itemize}
        Для каждого нечётного $i$ блок находится в $S$. Такое $\gamma$ имеет минимальный возможный размер: $\An(\mathcal{S}_w(\Gamma)) = (2|\Gamma| + 1) \cdot \An(w)$.
        \item Пусть для любого гамильтонова множества полигональных путей $\gamma_w$ для $w$ размера $|w| - \An(w) - 1$, такого что первое и последнее ребро трансверсального пути не закрашены, существует полигональный путь, соединяющий первую и последнюю вершину трансверсального пути. Пусть $\gamma_w$ — какое-то из них. Конструкция для $\mathcal{S}_w^\circ(\Gamma_{(11)})$ из предыдущего пункта уже не подходит, поскольку в этом случае в ней будет цикл. Поэтому сборное число внутренней подстановки на единицу больше: $\An(\mathcal{S}_w^\circ(\Gamma_{(11)})) = \An(w) + 1$.

        Каждый блок из $S$ соединяет полигональным путём вершины $g_i$ и $g_{i + 1}$. Cборное чиcло подстановки начинает зависеть от сборного числа исходного графа:  $|S| \leq |\Gamma| - \An(\Gamma)$ и $\An(\mathcal{S}_w(\Gamma)) = (2|\Gamma| + 1) \cdot \An(w) + \An(\Gamma)$.
    \end{itemize}
\end{proof}


\section{Реализующее число для графов без петель}\label{sec:Romin}

В предыдущей главе мы изучили семейство $(1212)$-подстановок. Для простого сборного графа $\Gamma$ граф $\mathcal{S}_{(1212)}(\Gamma)$ не содержит петель и $|\mathcal{S}_{(1212)}(\Gamma)| = 5\cdot \An(\mathcal{S}_{(1212)}(\Gamma)) - 3$. Это дает оценку сверху на реализующее число для графов без петель.

\[
    \Romin(k) \leq 5k - 3
\]

В этой главе мы докажем что неравенство обращается в равенство при всех $k$.
Это достигается с помощью алгоритма $\G$ из \cite{MaksaevPreprint}, который по простому сборному графу $\Gamma$ жадно строит гамильтоново множество полигональных путей малого размера $\gamma$. В случае графов без петель мы получим оценку сверху $|\Gamma| \geq 5\cdot |\gamma| - 3 \geq 5 \cdot \An(\Gamma) - 3$.

Именно для графов с большим количеством петель алгоритм $\G$ выдает большие гамильтоновы множества полигональных путей. Чтобы справиться со случаем графов без петель, нам понадобится более тонкий анализ. 

\begin{lemma}[\cite{MaksaevPreprint}]\label{lemma:greedy-cons-edges}
    Пусть $\Gamma$ — простой сборный граф, где $e_1,e_2,\ldots,e_{2n - 1}$ его рёбра в порядке трансверсального обхода, а $\gamma$ — некоторое гамильтоново множество полигональных путей. Пусть натуральное $i$ таково, что $e_{i}, e_{i+1} \notin E(\gamma)$ и выполнено хотя бы одно из условий:
    \begin{itemize}
        \item $i=1$ и $e_{i+2} = e_3 \notin E(\gamma)$;
        \item рёбра $e_{i-1}, e_{i+2} \notin E(\gamma)$;
        \item  $i=2n-2$ и $e_{i-1} \notin E(\gamma)$.
    \end{itemize} 

    Тогда добавление либо $e_i$, либо $e_{i + 1}$ к $E(\gamma)$ задаёт корректное гамильтоново множество полигональных путей.  
\end{lemma}

Для полноты, представим доказательство из \cite{MaksaevPreprint}.

\begin{proof}
Заметим, что $\gamma$ — это объединение попарно вершинно-непересекающихся путей (возможно, нулевой длины). Условие леммы гарантирует, что добавляемое ребро $e \in \{e_i, e_{i+1}\}$ не является соседним в трансверсальном порядке с уже закрашенными рёбрами (кроме, возможно, $e_{i-1}$ и $e_{i+2}$, которые не принадлежат $E(\gamma)$). Следовательно, в графе, образованном $E(\gamma) \cup \{e\}$, степень каждой вершины не превышает $2$, а сам он состоит из попарно вершинно-непересекающихся путей и не более чем одного цикла.

Пусть $e_i = \{x, y\}$, $e_{i+1} = \{y, z\}$; величины $x, y, z$ могут совпадать. Предположим, что при добавлении $e_i$ к $E(\gamma)$ возникает цикл. Тогда $x$ и $y$ являются концами одного и того же пути $p \in \gamma$. Если $z \neq x$, то вершины $y$ и $z$ не могут быть концами какого-либо пути из $\gamma$ (в противном случае добавление $e_i$ не создало бы цикла из-за разрыва в $y$). Поэтому добавление $e_{i+1}$ не замыкает цикла и сохраняет свойство гамильтонова множества полигональных путей. Если же $z = x$, то степень вершины $x$ в $E(\gamma)$ равна $0$ (иначе $x, y$ не были бы концами одного пути), так что вершина $x$ покрывается одноточечным путём $\{x\} \in \gamma$. В этом случае добавление ребра $e_i$ допустимо.
\end{proof}

\begin{lemma}[\cite{MaksaevPreprint}]
    Пусть $\Gamma$ — простой сборный граф, где $e_1,e_2,\ldots,e_{2n - 1}$ его рёбра в порядке трансверсального обхода, $\gamma$ — множество полигональных путей, полученное в результате работы алгоритма $\G$. Пусть $E(\gamma) = \{e_{i_1}, e_{i_2},\ldots,e_{i_k}\}$ — ребра $\gamma$ в возрастающем порядке: $i_1 < i_2 <\ldots<i_k$.
    \begin{itemize}
        \item Одно из первых двух ребер трансверсального пути закрашено: $e_1 \in E(\gamma)$ либо $e_2 \in E(\gamma)$. Исключением является петля, так как у него лишь одно ребро в трансверсальном пути.
        \item Закрашенные ребра разделены интервалами ровно из одного или двух незакрашенных ребер: $i_{j + 1} = i_j + 2$ либо $i_{j + 1} = i_j + 3$ для всех $j$.
        \item За последним закрашенным ребром следует не больше двух незакрашенных: $i_k \geq 2n - 3$.
    \end{itemize}
\end{lemma}

\begin{proof}
    Если первое ребро не закрашено, второе обязательно будет закрашено, так как в самом начале работы алгоритма применима лемма \ref{lemma:greedy-cons-edges} для первых двух ребер. 
    
    Пусть $\G$ закрасил очередное ребро $e_i$. В силу полигональности $e_{i + 1}$ закрашено не будет. В свою очередь, для $e_{i + 2}$ и $e_{i + 3}$ применима лемма \ref{lemma:greedy-cons-edges}: Какое-то из этих двух точно будет закрашено. Следовательно, после любого закрашенного ребра следует не больше двух незакрашенных.
\end{proof}

 Заметим, что первое ребро $e_1$ остается незакрашенным только если оно является \emph{петлей}. Действительно, множество $E' = \{e_1\}$ задает некорректное гамильтоново множество полигональных путей только если в графе ограничения $\Gamma$ на $E'$ есть цикл длины один. 

Пусть $\Gamma$ — простой сборный граф без петель, $e_1,e_2,\ldots,e_{2n-1}$ — его рёбра в порядке трансверсального обхода, а $\gamma = \G(\Gamma)$ — множество полигональных путей, полученное алгоритмом $\G$. 
Обозначим через $E(\gamma) = \{e_{i_1}, e_{i_2},\ldots,e_{i_k}\}$ рёбра пути $\gamma$, индексы которых идут в возрастающем порядке: $i_1 < i_2 < \dots < i_k$. 

Разобьём трансверсальный путь на непересекающиеся сегменты последовательных рёбер по следующему правилу: каждый сегмент начинается с закрашенного ребра $e_{i_j}$ и содержит все идущие за ним незакрашенные рёбра вплоть до следующего закрашенного (не включая его). Так как ребро $e_1$ трансверсального пути закрашено по построению, каждое ребро попадает ровно в один сегмент. 
Из свойств алгоритма $\G$ длина любого сегмента не превышает трёх, 
и лишь последний сегмент может состоять из одного ребра.

\begin{definition}
Для построенного выше разбиения обозначим через $\A(\Gamma)$ и $\B(\Gamma)$ 
семейства сегментов из двух и трёх рёбер соответственно:
\[
    \A(\Gamma) = \{(e_{i_j}, e_{i_j + 1}) : i_{j} + 2 = i_{j + 1} 
                 \vee i_j + 1 = 2n - 1\},
\]
\[
    \B(\Gamma) = \{(e_{i_j}, e_{i_j + 1}, e_{i_j + 2}) : i_{j} + 3 = i_{j + 1} 
                 \vee i_j + 2 = 2n - 1\}.
\]
Положим $\alpha(\Gamma) = |\A(\Gamma)|$ и $\beta(\Gamma) = |\B(\Gamma)|$. 
Если из контекста ясно, о каком графе идёт речь, аргумент $\Gamma$ будем опускать.
\end{definition}

Заметим, что числа $\alpha$ и $\beta$ могут поменяться при обращении графа: от порядка обработки ребер сильно меняется ход работы алгоритма $\G$. Дальше будут предъявлены примеры графов, для которых $\G$ строит множества полигональных путей сильно больше, чем для их обращений (напомним, что обращение \emph{не влияет} на сборное число). Именно поэтому \emph{симметричная} версия жадного алгоритма является логичным усилением $\G$ (см. определение \ref{def:sym-G}).

Зафиксируем некоторый простой сборный граф без петель $\Gamma$ и множество полигональных путей $\gamma$, ассоциированное с работой $\G$. Выразим имеющиеся параметры через $\alpha$ и $\beta$, разобрав два случая.

\begin{itemize}
    \item Ребро $e_{2n - 1}$ не закрашено:
    \[
    \left\{
    \begin{aligned}
        & 2|\Gamma| - 1 = 2\alpha + 3\beta, \\
        & |E(\gamma)| = \alpha + \beta, \\
        & |\Gamma| = |\gamma| + |E(\gamma)|
    \end{aligned} 
    \right. 
    \implies{
        \left\{
        \begin{aligned}
            & 2\cdot (|\Gamma| - |E(\gamma)|) = \beta + 1, \\
            & |\gamma|= |\Gamma| - |E(\gamma)|
        \end{aligned} 
        \right. 
        \implies
        \ 2\cdot|\gamma| = \beta + 1
    }
    \]
    \item Ребро $e_{2n - 1}$ закрашено:
    \[
    \left\{
    \begin{aligned}
        & 2|\Gamma| - 1 = 2\alpha + 3\beta + 1, \\
        & |E(\gamma)| = \alpha + \beta + 1, \\
        & |\Gamma| = |\gamma| + |E(\gamma)|
    \end{aligned} 
    \right.
    \implies{
        \left\{
        \begin{aligned}
            & 2\cdot (|\Gamma| - |E(\gamma)|) = \beta, \\
            & |\gamma|= |\Gamma| - |E(\gamma)|
        \end{aligned} 
        \right. 
        \implies
        \ 2\cdot|\gamma| = \beta
    }
    \]
\end{itemize}

Мы добьёмся ограничения сверху на $|\gamma|$ через ограничение сверху на $\beta$. Мы покажем, что в случае графов без петель трёхрёберных сегментов всегда не сильно больше двухрёберных: $\beta \leq \alpha + 1$. Заметим, без ограничения на отсутствие петель ситуация была бы кардинально другой: у петельных подстановок \emph{совсем нет} двухрёберных сегментов. Именно поэтому случай графов без петель требует больше технических усилий.

Пусть $B = \{b_1, \dots, b_{\beta}\}$ трёхрёберные сегменты в порядке трансверсального обхода. Напомним, что $b_j = (e_{i_j}, e_{i_j + 1}, e_{i_j + 2})$. 
Через $S_j$ обозначим множество закрашенных рёбер, которые стоят в трансверсальном пути не позже сегмента $b_j$.
\[
    S_j = \{e_t \in E(\gamma) : t \leq i_j + 2\}
\]

\begin{definition}
    Будем говорить что полигональный путь $a$ целиком содержится в полигональном пути $b$ если $E(a) \subset E(b)$. Обозначим это отношение через $a \subset b$.
\end{definition}

\begin{remark}\label{remark:c-subset}
    Любой полигональный путь $c \subset S_{j_1}$ всегда содержится целиком в каком-то полигональном пути $c' \subset S_{j_2}$ при $j_1 \leq j_2$.
\end{remark}

\begin{proof}
    Любое закрашивание ребра во время работы алгоритма $\G$ объединяет какие-то два полигональных пути в один. Оба изначальных пути целиком содержатся в результирующем пути. Отношение <<$a \subset b$>> на путях транзитивно, так как транзитивно аналогичное отношение на множествах рёбер путей.
\end{proof}

\begin{conjecture}\label{conj:B-properties}
    Сегменты из $\B$ имеют следующие свойства:
    \begin{enumerate}
        \item Ребро $e_{i_j}$ закрашено, а ребра $e_{i_j + 1}, e_{i_j + 2}$ не закрашены.
        \item Обозначим через $x_j$ и $y_j$ вершины ребра $e_{i_j + 2}$ (трансверсальный путь проходит через $x_j$ в $y_j$). На момент обработки ребра $e_{i_j + 2}$ существует полигональный путь, такой что вершины $x_j, y_j$ являются его концами. Обозначим этот путь через $c_j$.
        \item Вершины $x_j$ и $y_j$ являются вторыми вхождениями для ребра $e_{i_j + 2}$.
        \item Путь $c_j$ является максимальным по включению полигональным путем в $S_j$.
    \end{enumerate}    
\end{conjecture}

\begin{proof}
    Докажем каждый пункт по отдельности.
    \begin{enumerate}
        \item Верно по построению.
        \item Заметим, что $E(c_j) \subset S_j$ по определению. Раз $e_{i_j + 2}$ не было закрашено, его добавление к $S_j$ порождает некорректное гамильтоново множество полигональных путей. Полигональность не нарушается в силу пункта 1. Значит нарушается отсутствие циклов. Это и означает что существует полигональный путь с описанными свойствами. 
        \item  Вершины $x_j$ и $y_j$ различны, так как $e_{i_j + 2}$ не петля. Это значит что $c_j$ положительной длины, и в $S_j$ есть ребра инцидентные этим вершинам. Следовательно, первые вхождения $x_j$ и $y_j$ не позже ребра $e_{i_j}$.
        \item Ни одно ребро из $S_j$ не инцидентно вторым вхождениям $x_j$ и $y_j$. Значит, в силу полигональности, ровно одно ребро из $S_j$ инцидентно $x_j$ и ровно одно ребро из $S_j$ инцидентно $y_j$. Это и значит что путь $c_j$ является максимальным по включению.
    \end{enumerate}
\end{proof}

\begin{lemma}\label{lemma:disjoint-c}
    Полигональные пути $\{c_j\}_{j = 1}^\beta$ попарно не пересекаются по рёбрам.
\end{lemma}

\begin{proof}
    От противного. Пусть существует ребро $e \in c_j \cap c_k$ при $j < k$. В силу замечания \ref{remark:c-subset} $c_j \subset c_k$. 

    Второму вхождению вершины $x_j$ не инцидентны ребра из $S_k$ (см. пункт 1 утверждения \ref{conj:B-properties}). Это значит, что $x_j$ является концевой вершиной в $c_k$. Следовательно, второе вхождение $x_j$ лежит одновременно в сегментах $b_j$ и $b_k$. Трехреберные сегменты по построению не могут пересекаться. Противоречие.
\end{proof}

Обозначим через $m_j \in c_j$ ребро, которое появляется в трансверсальном пути первым среди других рёбер пути $c_j$. Во время работы $\G$ оно закрашивается раньше других рёбер пути $c_j$. Пути $c_j$ не пересекаются по рёбрам, а значит все $m_j$ различны.

\begin{lemma}
    Обе вершины ребра $m_j$ являются первыми вхождениями.
\end{lemma}

\begin{proof}
От противного. Пусть в каком-то фиксированном ребре $m_j$ вершина $z$ является вторым вхождением. Вершина $z$ не совпадает с концевыми вершинами пути $c_j$ ($x_j$ и $y_j$) так как их вторые вхождения не участвуют в $c_j$. Значит, существуют два ребра из $c_j$, инцидентные $z$: $ez_1$ (первое вхождение) и $ez_2 = m_j$ (второе). Однако $ez_1$ находится в трансверсальном пути раньше, чем $m_j$. Противоречие.
\end{proof}

\begin{lemma}\label{lemma:m-after-A}
    Если ребро $m_j$ не является первым в трансверсальном пути, оно следует после двухрёберного сегмента из $\A$.
\end{lemma}

\begin{proof}
    От противного. Пусть ребро $m_j$ следует после сегмента $b_j \in B$. Тогда $y_j$ является вторым вхождением в ребре $m_j$. Противоречие.
\end{proof}

\begin{corollary}\label{cor:a+1geqb}
    Для любого простого сборного графа без петель $\alpha + 1 \geq \beta$. 
\end{corollary}

\begin{proof}
    Мы инъективно сопоставили каждому трехреберному сегменту $b_j$ ребро $m_j$, которое либо является первым в трансверсальном пути, либо следует за каким-то двухреберным сегментом. Это и дает нам неравенство на мощностях семейств $\A$ и $\B$.
\end{proof}

\begin{theorem}\label{th:5k-3}
    Пусть $\Gamma$ — простой сборный граф без петель. Тогда $|\Gamma| \geq 5 \cdot \An(\Gamma) - 3$.
\end{theorem}

\begin{proof}
    Пусть $\gamma$ — гамильтоново множество полигональных путей для $\Gamma$, ассоциированное с работой алгоритма $\G$. Разберём два случая.

    \begin{itemize}
    \item Ребро $e_{2n - 1}$ не закрашено.
    \[
    \left\{
    \begin{aligned}
        & 2|\Gamma| - 1 = 2\alpha + 3\beta, \\
        & |E(\gamma)| = \alpha + \beta, \\
        & |\Gamma| = |\gamma| + |E(\gamma)| \\
        & \alpha + 1 \geq \beta 
    \end{aligned} 
    \right. 
    \implies{
        \left\{
        \begin{aligned}
            & 2|\Gamma| \geq 5\beta - 1, \\
            & 2\cdot|\gamma| = \beta + 1 \\
        \end{aligned} 
        \right.     
    }
    \implies |\Gamma| \geq 5|\gamma| - 3
    \]
    \item Ребро $e_{2n - 1}$ закрашено.
    \[
    \left\{
    \begin{aligned}
        & 2|\Gamma| - 1 = 2\alpha + 3\beta + 1, \\
        & |E(\gamma)| = \alpha + \beta + 1, \\
        & |\Gamma| = |\gamma| + |E(\gamma)| \\
        & \alpha + 1 \geq \beta 
    \end{aligned} 
    \right.
    \implies{
        \left\{
        \begin{aligned}
            & 2|\Gamma| \geq 5\beta, \\
            & 2\cdot|\gamma| = \beta \\
        \end{aligned} 
        \right.
    } 
    \implies |\Gamma| \geq 5|\gamma|
    \]
\end{itemize}

Получаем $|\Gamma| \geq 5\cdot|\gamma| - 3 \geq 5 \cdot \An(\Gamma) - 3$.
\end{proof}

\begin{theorem}\label{th:Romin}
    Реализующее число для сборных графов без петель имеет следующий вид.
    \[
    \Romin(k) = 5k - 3.
    \]
\end{theorem}

\begin{proof}
    Оценка снизу $\Romin(k) \geq 5k - 3$ следует напрямую из теоремы \ref{th:5k-3}. В качестве примера графа размера $5k - 3$ со сборным числом $k$ подойдет любая $(1212)$-подстановка (см. следствие \ref{cor:pretzelsat5k-3}). Это дает оценку сверху $\Romin(k) \leq 5k - 3$
\end{proof}

\section{Графы без петель с наибольшим сборным числом}\label{sec:max-an}

В этой главе мы исследуем семейство простых сборных графов без петель с максимальным сборным числом при фиксированном размере: $\operatorname{argmax}\{\An(\Gamma) : |\Gamma| = n,\ \Gamma \text{ - без петель}\}$.

\begin{conjecture}
    Пусть даны целые числа $k \geq 1$ и $\D, \ 0 \leq \D \leq 4$. Существует простой сборный граф без петель размера $5k - 3 + \D$ со сборным числом $k$.
\end{conjecture}

\begin{proof}
    Утверждение для $\D = 0$ напрямую следует из теоремы \ref{th:Romin}. Определим следующие графы.

    \begin{enumerate}
        \item $\Gamma_1 = 123231456564$.
        \item $\Gamma_2 = 1212$.
        \item $\Gamma_3 = 123231$.
        \item $\Gamma_4 = 12123434$.
    \end{enumerate}

    Заметим, что из теоремы \ref{th:Romin} следует, что $\An(\Gamma) = 1$ для любого простого графа без петель $\Gamma$ размера $|\Gamma| \leq 6$. Это значит, что $\An(\Gamma_1) = \An(\Gamma_2) = \An(\Gamma_3) = \An(\Gamma_4) = 1$. Графы $\Gamma_2, \Gamma_3, \Gamma_4$ не аддитивны как слева, так и справа, так как $|\Gamma_i \circ \Gamma_{(1)}| = |\Gamma_{(1)} \circ \Gamma_i| \leq 5$ для всех $2 \leq i \leq 4$ (см. лемму \ref{lem:additivity-criterion}). С другой стороны, $\Gamma_1$ аддитивен. Чтобы это доказать, нужно лишь проверить, что $\An(\Gamma_1 \circ \Gamma_{(1)}) = \An(\Gamma_{(1)} \circ \Gamma_1) = 2$. Простые графы без петель с искомыми свойствами строятся следующим образом. Напомним, что $\Gamma_{(1)}$ обозначает простой сборный граф петли.

    \begin{itemize}
        \item $\Gamma_3$ для $k = 1$ и $\D = 1$.
        \item $\mathcal{S}_{1212}(\Gamma) \circ \Gamma_{\D}$ для $\D = 1$ и $k \geq 2$, где $\Gamma$ — любой простой сборный граф размера $|\Gamma| = k - 2$. В силу аддитивности $\Gamma_\D$, сборное число равно $\An(\mathcal{S}_{1212}(\Gamma) \circ \Gamma_{\D}) = \An(\mathcal{S}_{1212}(\Gamma)) + 1 = k$.
        \item $\mathcal{S}_{1212}(\Gamma) \circ \Gamma_{\D}$ для $\D \geq 2$, где $\Gamma$ — любой простой сборный граф размера $|\Gamma| = k - 1$. В силу неаддитивности $\Gamma_\D$, сборное число равно $\An(\mathcal{S}_{1212}(\Gamma) \circ \Gamma_{\D}) = \An(\mathcal{S}_{1212}(\Gamma)) = k$.
    \end{itemize}
\end{proof}

Теперь мы знаем максимальное сборное число среди графов без петель фиксированного размера.

\[
    \max\{\An(\Gamma) : |\Gamma| = n,\ \Gamma \text{ - без петель}\} = \left\lfloor\frac{n + 3}{5}\right\rfloor.
\]

\subsection{Графы размера $5k-3$}\label{sec:5k-3}

В этом разделе мы докажем, что все простые сборные графы без петель $\Gamma$, для которых выполняется равенство
\begin{equation}\label{eq:max5k-3}
    |\Gamma| = 5 \cdot \An(\Gamma) - 3,
\end{equation}
изоморфны какой-то $(1212)$-подстановке. Пусть $\gamma$ — гамильтоново множество полигональных путей, которое строит $\G$ для $\Gamma$. Для графов, для которых выполняется уравнение \eqref{eq:max5k-3}, множество $\gamma$ является оптимальным.
\[
    |\Gamma| = 5 \cdot |\gamma| - 3
\]
Однако это не является достаточным условием. Грубо говоря, алгоритм $\G$ плохо справляется с отделением графов с наибольшим сборным числом от общей массы. Продемонстрируем это на примере.

\begin{figure}[htbp]
    \centering
    \includegraphics[width=0.56\textwidth]{img/1234125345.pdf}
    \caption{Жадная (слева) и оптимальная (справа) покраска два-слова 1234125345.}
    \label{fig:1234125345}
\end{figure}

\begin{example}
    Пусть $\Gamma_1$ является сборным графом для слова $(1234125345)$. Рассмотрим следующий ряд:

    \[
    \Gamma_k = \underbrace{\Gamma_1 \circ \Gamma_1 \circ \dots \circ \Gamma_1}_{k - 1 \text{ раз}}\circ \Gamma_{(1212)} \quad  \forall k \geq 0. 
    \]

    где под $\Gamma_{(1212)}$ имеется в виду граф, соответствующий слову $(1212)$.

    \begin{itemize}
        \item В $\Gamma_k$ нет петель,
        \item $|\Gamma_k| = 5k - 3$ и $\An(\Gamma_k) = 1$.
        \item Алгоритм $\G$ строит для $\Gamma_k$ гамильтоново множество полигональных путей размера $k$. 
    \end{itemize}

\end{example}

\begin{proof}
    В рисунке \ref{fig:1234125345} изображена жадная и оптимальная покраска графа $\Gamma_1$. Покрашеные ребра имеют красный цвет, непокрашеные ребра --- черный. Пунктиром изображено ребро соединяющее две копии графа $\Gamma_1$. 

    Посчитаем размер гамильтоновых множеств полигональных путей построенных алгоритмом $\G$ $\gamma_\G$ и оптимального множества $\gamma_{opt}$.

    \begin{itemize}
        \item Жадный алгоритм красит $4 \cdot (k - 1) + 1$ ребра, а значит $|\gamma_\G| = 5k - 3 - |E(\gamma_{\G})| = k$.
        \item В оптимальном множестве покрашено $5 \cdot (k - 1) + 1$ ребра, а значит $|\gamma_{opt}| = 5k - 3 - |E(\gamma_{opt})| = 1$.
    \end{itemize}
\end{proof}


\begin{conjecture}\label{conj:G-properties}
    Пусть $\gamma$ гамильтоново множество полигональных путей, которое строит $\G$ для простого сборного графа без петель $\Gamma$, такое что $|\Gamma| = 5 \cdot |\gamma| - 3$. Тогда $\gamma$ имеет следующие свойства:

    \begin{enumerate}
        \item Заключительное ребро трансверсального пути $e_{2n - 1}$ не закрашено.
        \item $\alpha + 1 = \beta$.
        \item $2\cdot |\gamma| = \beta + 1$.
        \item После каждого двухрёберного сегмента $a \in \A$ следует некоторое ребро $m_j$. Первое ребро трансверсального пути является $m_j$.
    \end{enumerate}
\end{conjecture}

\begin{proof}
    Докажем каждый пункт по отдельности.
    \begin{enumerate}
        \item Случай, когда ребро $e_{2n - 1}$ закрашено, нам не подходит, поскольку $|\Gamma| \geq 5 \cdot |\gamma|$ (см. теорему \ref{th:5k-3}).
        \item Последнее неравенство из теоремы \ref{th:5k-3} обращается в равенство только если вся цепочка обращается в равенство.
        \item Следует из первого пункта и теоремы \ref{th:5k-3}.
        \item Все ребра $\{m_j\}_{j=1}^\beta$ либо следуют за сегментом из $\A$, либо являются первым ребром в трансверсальном пути согласно лемме~\ref{lemma:m-after-A}. Количество мест, в которых могут оказаться ребра $\{m_j\}_{j=1}^\beta$, совпадает с их количеством: $\beta = \alpha + 1$. 
    \end{enumerate}
\end{proof}

Сегмент из $\A$ не может замыкать трансверсальный путь (см. пункт 4 утверждения \ref{conj:G-properties}). 
Следовательно, последний трехреберный сегмент $b_{\beta} \in \B$ замыкает трансверсальный путь. Вершину, что следует после сегмента $b_j \in \B$ где $j \neq \beta$, будем обозначать $z_j$.

\begin{lemma}\label{lemma:z-properties}
    Для любой пары $j < \beta, k \leq \beta$ ни одно ребро из пути $c_k$ не инцидентно вершине $z_j$.
\end{lemma}

\begin{proof}
    От противного. Пусть существуют индексы $j,k$, такие что ребро $e \in c_k$ инцидентно $z_j$. Из пункта 3 утверждения \ref{conj:B-properties} следует, что все вхождения вершин из $c_j$ находятся раньше в трансверсальном пути, чем $z_j$. Если $k \leq j$, то все вхождения вершин из $c_k$ стоят раньше в трансверсальном пути, чем $z_j$. Ребро $e$ не могло бы существовать.
    
    Остается вариант $j < k$. Обозначим ребро, что следует за сегментом $b_j$ и соединяет вершины $y_j$ и $z_j$ через $e'$. Ребро $e'$ соединяет пути $c_j$ и $c_k$. Причем $c_j\subset S_k$ и $e', e \in S_k$. Следовательно, $c_j \subset c_k$. Это противоречит лемме \ref{lemma:disjoint-c}.
\end{proof}

\begin{corollary}
    Пусть $\Gamma$ --- простой сборный граф без петель, а $\gamma$ — множество полигональных путей, полученное в результате работы алгоритма $\G$. Пусть $|\Gamma| = 5\cdot |\gamma| - 3$. Тогда все пути $c_j$ имеют единичную длину.
\end{corollary}

\begin{proof}
    Рассмотрим произвольное ребро $e \in E(\gamma)$. Если оно является первым в трансверсального пути $\Gamma$, либо следует после сегмента из $\A$, то оно является ребром $m_j \in c_j$ (пункт 4 утверждения \ref{conj:G-properties}). Иначе ребро следует после сегмента из $\B$, а значит, не может быть частью какого-либо пути $c_j$ по лемме~\ref{lemma:z-properties}. Следовательно, любой путь $c_j$ имеет единичную длину.
\end{proof}

\begin{lemma}
    Пусть $\Gamma$ -- простой сборный граф без петель, а $\gamma$ — множество полигональных путей, полученное в результате работы алгоритма $\G$. Пусть $|\Gamma| = 5\cdot |\gamma| - 3$. Тогда существует разбиение вершин $\{z_1,\ldots, z_{\beta - 1}\}$ на пары $(z_{p_k}, z_{q_k})$, такое что $z_{p_k} = z_{q_k} \quad \forall k$.
\end{lemma}

\begin{proof}
    Пусть рёбра $e_1, e_2$ инцидентны вхождению $z_j$, отличному от того, что находится следом за $b_j$. Рёбра $e_1, e_2$ трансверсальны, $e_1$ находится раньше в трансверсальном пути, чем $e_2$.  Рассмотрим следующие случаи.

    \begin{itemize}
        \item Рёбра $e_1$ и $e_2$ закрашены. Это нарушает полигональность $\gamma$.
        \item Рёбра $e_1$ и $e_2$ не закрашены. Два трансверсальных незакрашенных ребра, по определению, бывают только в трехреберных сегментах из $\B$. В таком случае $z_j$ совпадает с вершиной $x_k$ для какого-то сегмента $b_k$. Это противоречит лемме \ref{lemma:z-properties}, так как $x_k$ является концом пути положительной длины $c_k$.
        \item  Ребро $e_1$ не закрашено, ребро $e_2$ закрашено. Так как $e_2$ отличается от всякого $m_k \in c_k$ (см. лемму \ref{lemma:z-properties}), оно должно следовать после какого-то трехреберного сегмента $b_k$. Однако это бы означало, что $z_j$ совпадает с $y_k$. Это противоречит лемме \ref{lemma:z-properties}, так как $y_k$ является концом пути положительной длины $c_k$.
        \item  Ребро $e_1$ закрашено, ребро $e_2$ не закрашено. Так как $e_1$ отличается от всякого $m_k \in c_k$ (см. лемму \ref{lemma:z-properties}), оно должно следовать после какого-то трехреберного сегмента $b_k$. Следовательно, вершина $z_j$ совпадает с вершиной $z_k$.
    \end{itemize}
\end{proof}

Мы вводим понятие \textit{паттерна} два-слова, которое упрощает его структуру до каталанова объекта (объекта изоморфного правильной скобочной последовательности). Дальше мы увидим, что этот объект сохраняет достаточно информации, чтобы с ним было удобно работать. 

\begin{definition}
    Слово $\pattern(w)$ в алфавите $\{1,2\}$, полученное из два-слова $w$ путём замены каждой буквы на номер её вхождения, будем называть \textit{паттерном} два-слова $w$.
\end{definition}

\begin{conjecture}
    Паттерн два-слова имеет следующие свойства:

    \begin{enumerate}
        \item $\pattern(w)$ изоморфен правильной скобочной последовательности.
        \item Обозначим через $\operatorname{Swap}$ отображение $\{1,2\}^* \to \{1,2\}^*$, заменяющее все буквы на противоположные (1 на 2 и 2 на 1). Тогда $\mathcal{P}(w^R) = \operatorname{Swap}(\pattern(w)^R)$. 
    \end{enumerate}
\end{conjecture}

\begin{proof} 
    Докажем каждый пункт по отдельности.
    \begin{enumerate}
        \item В два-слове одинаковое количество первых и вторых вхождений. В префиксе два-слова первых вхождений всегда не меньше, чем вторых вхождений.
        \item При чтении два-слова справа налево номер вхождения буквы меняется на противоположный (1 на 2 и 2 на 1).
    \end{enumerate}
\end{proof}

Ранее мы убедились, что рёбра из \(E(\gamma)\) сильнее связаны с сегментами, 
предшествующими им, чем с теми сегментами, в которых они непосредственно 
содержатся. Это наблюдение мотивирует перегруппировку рёбер, которую 
удобнее провести на языке вершин (предыдущее обсуждение велось на языке 
рёбер).

Пусть \(\Gamma\) — простой сборный граф без петель, а \(\gamma\) — множество 
полигональных путей, полученное в результате работы алгоритма \(\G\). 
Предположим, что \(|\Gamma| = 5\cdot |\gamma| - 3\). Для удобства обозначим 
\(k = |\gamma|\). Пусть \(w = w_1 w_2 \dots w_{2n}\) — два-слово, 
соответствующее \(\Gamma\). Разобьём \(w\) на непересекающиеся 
последовательные \emph{блоки букв}. В ходе разбиения будет выделено некоторое 
подмножество вершин графа \(\Gamma\), которое мы будем называть \emph{главным}. 
Каждый блок содержит не более двух символов и устроен по следующим 
правилам.

\begin{itemize}
    \item Блок размера один содержит ровно одно вхождение главной вершины. 
    Все вхождения главных вершин лежат в таких блоках.
    \item Блоки размера два, аналогично скобкам, бывают открывающими и 
    закрывающими. Каждому открывающему блоку биективно соответствует 
    закрывающий. Открывающий блок состоит из двух \emph{первых вхождений} 
    каких-то неглавных вершин \(u, v\); соответствующий ему закрывающий 
    блок — из \emph{вторых вхождений} тех же вершин \(u, v\).
    \item Всего имеется \(2k - 1\) открывающих блоков, \(2k - 1\) 
    закрывающих блоков и \(k - 1\) главных вершин.
    \item Слово \(w\) начинается с открывающего блока и заканчивается 
    закрывающим.
    \item За каждым закрывающим блоком, кроме последнего, следует блок 
    размера один, содержащий какую-то главную вершину.
\end{itemize}

\begin{conjecture}\label{conj:max-An-generic-struct}
    Для графа \(\Gamma\) с описанными выше свойствами существует 
    единственное корректное разбиение на блоки.
\end{conjecture}

\begin{proof}
    Заметим, что \(\alpha + 1 = \beta = 2k - 1\).
    Установим соответствие между элементами графа и построенными блоками.
    \begin{enumerate}
        \item Главные буквы отвечают вершинам \(\{z_j\}_{j=1}^\beta\).
        \item Рёбра между буквами одного открывающего блока в точности 
        совпадают с множеством \(\{m_j\}_{j=1}^\beta\).
        \item Закрывающие блоки состоят из вторых вхождений вершин 
        \(x_j, y_j\).
    \end{enumerate}

    Теперь убедимся, что такое разбиение удовлетворяет всем необходимым 
    свойствам.
    \begin{itemize}
        \item Трансверсальный путь графа \(\Gamma\) начинается с ребра 
        \(m_j\).
        \item Вершины \(x_j, y_j\) являются концами однорёберного пути 
        \(c_j\); следовательно, \(x_j, y_j\) действительно представляют 
        собой вторые вхождения вершин, первые вхождения которых образуют 
        \(m_j\).
        \item Вершины \(z_j\) при \(j \neq \beta\) следуют после блока 
        \(b_j\). Подслово \(\{z_j\}\) действительно является два-словом 
        размера \(k - 1\).
        \item С одной стороны, непосредственно перед открывающим блоком формируется двухрёберный сегмент. С другой стороны, после каждого двухрёберного сегмента расположено ребро $m_j$ (см. пункт~4 утверждения ~\ref{conj:G-properties}).
        \item Трёхрёберный сегмент замыкает трансверсальный путь графа 
        \(\Gamma\) (см. пункт~4 утверждения ~\ref{conj:G-properties}), 
        поэтому закрывающий блок замыкает слово \(w\).
    \end{itemize}
\end{proof}

Обращение два-слова $w$ не меняет сборное число, но кардинально меняет ход работы $\G$. Результат работы жадного алгоритма для слова $w^R$ может оказаться лучше, чем для $w$. Это мотивирует нас изучить симметричную версию жадного алгоритма.

\begin{definition}\label{def:sym-G}
    Пусть \(\Gamma\) — простой сборный граф. \textit{Симметричным жадным 
    алгоритмом} \(\G_s\) назовём следующий итеративный процесс. 
    Алгоритм \(\G\) применяется к графу \(\Gamma\) и к его 
    обращению \(\Gamma^R\), в результате чего получаются гамильтоновы 
    множества полигональных путей \(\gamma_1\) и \(\gamma_2\) 
    соответственно. Алгоритм \(\mathcal{G}_s\) возвращает то из двух 
    множеств, которое содержит меньше путей.
\end{definition}


\begin{corollary}
    Пусть \(\Gamma\) — простой сборный граф без петель, а \(\gamma\) — 
    множество полигональных путей, полученное в результате работы 
    алгоритма \(\G\). Предположим, что \(|\Gamma| = 5\cdot |\gamma| - 3\). 
    Тогда выполняются следующие два утверждения.
    \begin{enumerate}
        \item \(\pattern(w)\) соответствует регулярному выражению 
        \texttt{\^{}11(11|221|222)*22}.
        \item \(\pattern(w)\) соответствует регулярному выражению 
        \texttt{\^{}11(22|111|211)*22}.
    \end{enumerate}
\end{corollary}

\begin{proof}
    Открывающий блок даёт в паттерн вклад \texttt{11}. Закрывающий блок 
    вместе со следующей за ним главной вершиной даёт вклад \texttt{221} 
    или \texttt{222}. Поэтому \(\pattern(w)\) описывается первым из 
    указанных регулярных выражений.

    Сборное число не меняется при обращении графа, так что 
    \(\pattern(w^R)\) также соответствует первому регулярному выражению. 
    Обращая обе части, получаем, что \(\pattern(w)\) соответствует 
    второму регулярному выражению.
\end{proof}

\begin{conjecture}
    Пересечение языков, задаваемых регулярными выражениями 
    \texttt{\^{}(11|221|222)*} и \texttt{\^{}(22|111|211)*}, задаётся 
    выражением  \texttt{\^{}(22?11|111111|222222|2222211111)*}.
\end{conjecture}

\begin{proof}
    Утверждение проверяется несложным перебором (см. рисунок \ref{fig:word-tree}).
\end{proof}

    \centering
    \includegraphics[width=0.56\textwidth]{img/ff.pdf}
    \caption{Префиксное дерево слов 111111, 22111, 22211, 2222211111, 
    222222}
    \label{fig:word-tree}
\end{figure}

Регулярные выражения не способны полностью проверить согласованность 
графов со всеми свойствами описанной конструкции — часть информации 
неизбежно теряется. Чтобы учесть её, проанализируем количество 
открывающих и закрывающих блоков в элементах паттерна.

\begin{itemize}
    \item \texttt{22111} и \texttt{22211} содержат по одному 
    открывающему и одному закрывающему блоку как при чтении слева 
    направо, так и при чтении справа налево.
    \item \texttt{2222211111} содержит по два открывающих и два 
    закрывающих блока в обоих направлениях чтения.
    \item \texttt{222222} состоит из двух закрывающих блоков, а его 
    обращение \texttt{111111} — из трёх открывающих блоков.
\end{itemize}

Таким образом, у каждого фрагмента \texttt{22111}, \texttt{22211} и 
\texttt{2222211111} количество открывающих и закрывающих 
блоков одинаково суммарно при чтении слева направо и справа налево. В то же 
время пара \texttt{222222} и \texttt{111111} даёт на один открывающий 
блок больше.

\begin{conjecture}
    \(\pattern(w)\) соответствует 
    регулярному выражению 
    \texttt{\^{}11(22111|22211|2222211111)*22}.
\end{conjecture}

\begin{proof}
    От противного. Предположим, что \(\pattern(w)\) содержит блоки 
    \texttt{222222} или \texttt{111111}. Тогда, в зависимости от 
    направления чтения, у слова \(w\) окажется больше открывающих 
    блоков, чем закрывающих. Однако в описанной конструкции количества 
    открывающих и закрывающих блоков совпадают. Противоречие.
\end{proof}

Фрагмент \texttt{2222211111} тоже можно исключить. Для этого нужно, чтобы для открывающих и закрывающих блоков выполнялось свойство правильной скобочной последовательности: в любом префиксе открывающих блоков не меньше закрывающих.

\begin{conjecture}
    \(\pattern(w)\) соответствует регулярному выражению \texttt{\^{}11(22111|22211)*22}
\end{conjecture}

\begin{proof}
    От противного. Пусть существует фрагмент \(b\) вида \texttt{2222211111}. Вплоть до \(b\) не включительно открывающие и закрывающие блоки чередуются. Фрагмент \(b\) начинается с двух закрывающих блоков, поэтому у паттерна существует префикс слова, содержащий больше закрывающих блоков, чем открывающих. Это противоречит свойствам конструкции.
\end{proof}

Регулярное выражение \texttt{\^{}11(22111|22211)*22} удобнее записать как \texttt{\^{}(11221|11222)*1122}. Открывающие и закрывающие блоки чередуются в таком слове. Между парой соседних главных вершин находится копия слова \(1212\). 
Это в точности совпадает с определением \((1212)\)-подстановки \(\mathcal{S}_{(1212)}\). 

\begin{corollary}
    Простой сборный граф без петель \(\Gamma\) имеет максимальное сборное число \(5\cdot \An(\Gamma) - 3 = |\Gamma|\) тогда и только тогда, когда существует простой сборный граф \(\bar{\Gamma}\) (возможно, содержащий петли), такой, что \(\Gamma = \mathcal{S}_{(1212)}(\bar{\Gamma})\).
\end{corollary}

\begin{proof}
    Все такие \(\Gamma\) согласованы с \texttt{\^{}(11221|11222)*1122}, а значит совпадают с \((1212)\)-подстановкой. С другой стороны, мы знаем, что все \(1212\)-подстановки имеют максимальное возможное сборное число (см. следствие \ref{cor:pretzelsat5k-3}).
\end{proof}

\subsection{Обобщение метода анализа паттернов}\label{sec:description}

Перейдём к изучению простых сборных графов без петель с наибольшим 
сборным числом, для которых \(|\Gamma| = 5k - 3 + \D\), где 
\(1 \leq \D \leq 4\). Проще всего построить это изучение как 
обобщение метода анализа паттернов два-слов, развитого в 
разделе~\ref{sec:5k-3}. В настоящем разделе мы дадим общую 
характеризацию таких графов, оставаясь в рамках уже введённого языка.

Попытка честного анализа всех конфигураций немедленно приводит к 
нескольким принципиально различным случаям, каждый из которых даёт 
свои оценки. С похожим эффектом мы уже сталкивались ранее: в 
зависимости от того, закрашивает ли алгоритм \(\G\) последнее ребро 
трансверсального пути или нет, возникали разные неравенства для 
\(|\gamma|\) (см. теорему~\ref{th:5k-3}). Тогда мы сознательно 
разобрали оба случая по отдельности. Однако сейчас такой подход 
неприменим: число случаев экспоненциально зависит от \(\D\). 
Поэтому мы прибегнем к небольшому трюку, позволяющему объединить все 
случаи в один.

\begin{definition}
    Для каждого целого числа $\D, 0 \leq \D < 5$ обозначим через $\OPT_\D$ семейство простых сборных графов без петель $\Gamma$, таких, что $\Gamma$ и $\Gamma^R$ имеют следующие свойства:

    \begin{enumerate}
        \item Сборное число принимает максимальное значение: $|\Gamma| = \D + 5\cdot \An(\Gamma) - 3$.
        \item Трёхрёберный сегмент замыкает трансверсальный путь.
        \item Первое ребро в трансверсальном пути равно некоторому $m_j$, где множества $\{m\}_j$ задано алгоритмом $\G$.  
    \end{enumerate}
\end{definition}

При $\D > 0$ уже не все простые сборные графы без петель с максимальным сборным числом находятся в $\OPT_\D$. Чтобы это исправить, мы приведём их к нужному виду с помощью композиции с аддитивными словами.

\begin{figure}[htbp]
    \centering
    \includegraphics[width=1.06\textwidth]{img/sag.pdf}
    \caption{Раскраска подграфа $w^R = \mathcal{S}_{1212}^\circ(1212)\circ \Gamma_{1212}$ в $\hGamma = \Gamma_w \circ \Gamma \circ \Gamma_{w^R}$.}
    \label{fig:sag}
\end{figure}

\begin{conjecture}
    Пусть сборный граф без петель $\Gamma$ имеет максимальное сборное число $|\Gamma| = \D +5 \cdot \An(\Gamma) - 3$ для некоторого $0 \leq \D \leq 4$.
    Пусть $\hGamma = \Gamma_{1212} \circ \mathcal{S}_{1212}^\circ(1212) \circ\Gamma \circ \mathcal{S}_{1212}^\circ(1212) \circ \Gamma_{1212}$. Утверждается, что $\hGamma \in \OPT_\D$.
\end{conjecture}

\begin{proof}
    Слово $w = \Gamma_{1212} \circ \mathcal{S}_{1212}^\circ(1212)$ является аддитивным слева, а слово $w^R = \mathcal{S}_{1212}^\circ(1212) \circ \Gamma_{1212}$ аддитивным справа. Следовательно, $\An(\hGamma) = \An(\Gamma_w \circ \Gamma \circ \Gamma_{w^R}) = \An(\Gamma_w) + \An(\Gamma) + \An(\Gamma_{w^R}) = 4 + \An(\Gamma)$. Петель в $\hGamma$ нет по построению.
    
    \begin{enumerate}
        \item  Проверяем равенство: $|\hGamma| = 20 + |\Gamma| = \D+ 5 \cdot \An(\hGamma) - 3$
        \item  Всего есть два варианта как алгоритм $\G$ может закрасить $w^R$. Зависит это только от того, закрашено ли ребро, соединяющее его с остальными вершинами (см. рисунок \ref{fig:sag}, закрашенные ребра отображены пунктиром). В обоих случаях трансверсальный путь замыкает трёхрёберный сегмент из $\B(\hGamma)$.
        
        \item  Граф $\hGamma$ начинается с $\Gamma_{1212}$. Его первые три ребра формируют трёхрёберный сегмент из $\B(\hGamma)$. Первое ребро трансверсального пути равно $m_1$.
    \end{enumerate}

    Утверждения для $\hGamma^R$ следуют из того, что $\hGamma^R = \Gamma_w \circ \Gamma^R \circ \Gamma_{w^R}$.
\end{proof}

 Любой простой сборный граф без петель $\Gamma$, для которого существует $\hGamma \in \OPT_\D$ такой, что $\hGamma = \Gamma_{1212} \circ \mathcal{S}_{1212}^\circ(1212) \circ\Gamma \circ \mathcal{S}_{1212}^\circ(1212) \circ \Gamma_{1212}$, по аддитивности имеет максимальное сборное число. С другой стороны, для всех $\Gamma$ с максимальным сборным числом $\hGamma \in \OPT_\D$. Мы нашли инъекцию из простых сборных графов без петель в $\OPT_\D$. Чтобы построить прообраз инъекции нам достаточно изучить $\OPT_\D$.

 \begin{conjecture}
     Пусть простой сборный граф без петель $\Gamma \in \OPT_\D$ для некоторого $0 \leq \D \leq 4$. Тогда $\alpha(\Gamma) + 1 = \beta(\Gamma) + \D$.
 \end{conjecture}

\begin{proof}
    Для удобства обозначим $k = \An(\Gamma)$. Воспользуемся утверждением \ref{cor:a+1geqb}:

    \[
        \left\{
        \begin{aligned}
            & 2\cdot|\Gamma| - 1 = 2\alpha + 3\beta, \\
            & |\Gamma| - |\gamma| = \alpha + \beta, \\
            & |\Gamma| = 5\cdot k - 3 + \D, \\
            & \alpha + 1 \geq \beta 
        \end{aligned} 
        \right.
        \implies{} 
        \left\{
        \begin{aligned}
            & 10 \cdot k - 7 + 2\D = 2\alpha + 3\beta, \\
            & 2|\gamma| - 1 = \beta, \\
            & \alpha + 1 \geq \beta 
        \end{aligned} 
        \right.
    \]

    Рассмотрим первое равенство по модулю 5.
    \[
        \left\{
        \begin{aligned}
            & 2\beta + 2\D \equiv 2\alpha  + 2 \mod{5}, \\
            & \alpha + 1 \geq \beta 
        \end{aligned} 
        \right.
        \implies{} 
        \left\{
        \begin{aligned}
            & \alpha  + 1\equiv \beta + \D  \mod{5}, \\
            & \alpha + 1 \geq \beta 
        \end{aligned} 
        \right.
        \implies{\alpha + 1 \geq \beta + \D}
    \]

    Применим усиленное неравенство.

    \[
        \left\{
        \begin{aligned}
            & 5 \cdot (2k - 1) + 2\D \geq 5\beta + 2\D,\\
            & 2\cdot|\gamma| - 1 = \beta, \\
            & \alpha + 1 \geq \beta + \D 
        \end{aligned} 
        \right.
        \implies{k \geq |\gamma|}
    \]

    Сборное число $k = \An(\Gamma)$ по определению не больше размера любого гамильтонова множества полигональных путей $\gamma$, а значит $k = |\gamma|$. Последнее неравенство обращается в равенство только если вся цепочка также обратилась в равенство.
    
\end{proof}


\begin{conjecture}
    Пусть простой сборный граф $\Gamma \in \OPT_\D$ где $0 \leq \D \leq 4$. Существует ровно $\D$ двухрёберных сегментов, за которыми следует ребро \emph{отличное} от всех рёбер $m_j$.
\end{conjecture}

Такие рёбра мы будем называть \emph{аномальными}.
\begin{proof}
    Среди $\alpha + 1$ валидных мест, где могут оказаться рёбра $\{m_j\}_{j = 1}^\beta$, заняты ровно $\beta = \alpha + 1 - \D$. По определению семейства $\OPT_\D$ первое ребро трансверсального пути равно какому-то $m_j$. Поэтому аномальных рёбер ровно $\D$.
\end{proof}

\begin{definition}
    Аномальное ребро графа $\Gamma \in \OPT_\D$ называется \emph{базовым}, если оно содержится в каком-то из путей $c_j$.
\end{definition}

Мы будем различать базовые и небазовые аномальные рёбра в дальнейшем рассуждении.

\begin{conjecture}
    В базовых аномальных рёбрах любого графа $\Gamma \in \OPT_\D$ одинаковое количество первых и вторых вхождений вершин.
\end{conjecture}

\begin{conjecture}
    Рассмотрим вхождения вершин путей $c_j$ в два-слове графа. Два первых вхождения задействованы в $m_j$ и два вторых вхождения совпадают со вторыми появлениями $x_j$ и $y_j$. Всем остальным вхождениям соответствует некоторое базовое аномальное ребро.
\end{conjecture}

Аналогично случаю $\D = 0$, мы разобьём два-слово $w \in \OPT_\D$ на непересекающиеся последовательные блоки букв. Пусть $|w| = 5k - 3  + \D$ где $0 \leq \D \leq 4$.

В ходе разбиения будет выделено некоторое подмножество вершин графа \(\Gamma\), которое мы будем называть \emph{главным}. Каждый блок содержит не более двух символов и устроен по следующим правилам.

\begin{itemize}
    \item Блок размера один содержит ровно одно вхождение главной вершины. 
    \item Блоки размера два бывают открывающими, закрывающими и аномальными.
    \item Каждому открывающему блоку биективно соответствует 
    закрывающий, находящийся правее в трансверсальном пути. Открывающий блок состоит из двух \emph{первых вхождений} каких-то неглавных вершин; соответствующий ему закрывающий блок — из \emph{вторых вхождений}, возможно уже других вершин.
    \item Аномальные блоки бывают базовыми и небазовыми. В базовых блоках расположены неглавные буквы, а в небазовых — главные. Первых вхождений в базовых блоках столько же, сколько вторых вхождений. Пусть $\D_1, \D_2$ это количество базовых и небазовых аномальных блоков соответственно. Тогда $\D_1 + \D_2 = \D$.
    \item Всего имеется \(2k - 1\) открывающих блоков, \(2k - 1\) 
    закрывающих блоков и \(k - 1 + \D_2\) главных вершин.
    \item Слово \(w\) начинается с открывающего блока и заканчивается 
    закрывающим.
    \item За каждым закрывающим блоком, кроме последнего, следует блок 
    размера один, содержащий какую-то главную вершину.
\end{itemize}

Обозначим соответствие между элементами графа и блоками, которое задумывалось при таком разбиении.
\begin{enumerate}
    \item Главные буквы отвечают вершинам, которые не участвуют ни в одном пути из множества \(\{c_j\}_{j=1}^\beta\).
    \item Рёбра между буквами одного открывающего блока 
    совпадают с множеством \(\{m_j\}_{j=1}^\beta\).
    \item Закрывающие блоки состоят из вторых вхождений вершин 
    \(x_j, y_j\).
    \item Рёбра между буквами одного базового аномального блока совпадают с множеством базовых аномальных рёбер.
    \item Рёбра между буквами одного небазового аномального блока совпадают с множеством небазовых аномальных рёбер.
\end{enumerate}
Рассуждение о корректности конструкции во многом повторяет утверждения \ref{conj:max-An-generic-struct} и задействует свойства семейства $\OPT_\D$.

Паттерн два-слова $w \in \OPT_\D$ можно описать некоторым автоматным языком. Пусть $\mathcal{A} = \{11, 12, 21, 22\}$~--- язык паттернов аномальных блоков.

\[
L_\D = \{\, u \in \{1,2\}^* \mid u = 11\,x\,22,\;
u \in \bigl( \{11,\, 221,\, 222\} \cup \mathcal{A} \bigr)^*,\,
\#_\mathcal{A}(u) = \D \,\},
\]

\[
L_\D^R = \{\, u \in \{1,2\}^* \mid u = 11\,x\,22,\;
x \in \bigl( \{22,\, 211,\, 111\} \cup \mathcal{A} \bigr)^*,\,
\#_\mathcal{A}(u) = \D \,\},
\]

Для любого два-слова $v$, если $\pattern(v) \in L_\D$, 
то $\pattern(v^R) \in L_\D^R$.

\begin{conjecture}
    Пусть $w \in \OPT_\D$. Тогда 
    $\pattern(w) \in L_\D \cap L_\D^R$.
\end{conjecture}

\begin{proof}
    Аномальные блоки дают произвольный вклад 
    $a \in \mathcal{A}$. 
    Семейство инвариантных графов замкнуто 
    относительно обращения: $w^R \in \OPT_\D$. 
    Следовательно, $\pattern(w^R) \in L_\D$, 
    а значит, $\pattern(w) \in L_\D^R$.
\end{proof}

Слова $w$ и $w^R$ могут иметь совершенно разные 
паттерны аномалий. Каждая аномалия характеризуется 
двумя основными признаками:
\begin{enumerate}
    \item является ли она базовой;
    \item паттерн $a \in \mathcal{A}$.
\end{enumerate}

Выбрать аномалии для $w$ и $w^R$ можно 
$8^{2\D} = 64^{\D}$ способами. 
Для поиска подходящих паттернов предлагается 
следующий алгоритм.
\begin{enumerate}
    \item Перебираем паттерны аномалий 
    $a_1,\dots,a_\D \in \mathcal{A}$ и 
    $a_1',\dots,a_\D' \in \mathcal{A}$ 
    для $w$ и $w^R$ соответственно.
    \item Вычисляем пересечение соответствующих 
    автоматных языков. Фильтруем фрагменты 
    на предмет соответствия инвариантам, 
    не выразимым регулярными выражениями.
\end{enumerate}

Уже при $\D > 1$ количество автоматных языков 
становится ощутимо большим. В рамках данной 
работы был разобран лишь случай $\D = 1$.

\begin{conjecture}
    Зафиксируем два-слово $g$ и его $(1212)$-подстановку 
    $g' = \mathcal{S}_{1212}(g)$. 
    Пусть в слове $g'$ не встречаются символы 
    $1,2,3,4,5,6,7$ и $8$. 
    Тогда любое два-слово $w\in \OPT_1$ строится одним 
    из следующих способов.
    \begin{enumerate}
        \item Выберем произвольную копию слова $1212$ 
        и заменим её на произвольное слово $u$ из множества
        \[
        \begin{aligned}
        \{&121323,\, 123123,\, 123132,\, 123213,\, 
        123231,\\
        &1234545367878612,\, 1234545367878621,\\
        &1234567878634512,\, 1234567878634521\}.
        \end{aligned}
        \]
        
        \item Выберем произвольный фрагмент слова $g'$ 
        следующего вида:
        \[
            (1212)^i,\; g_i,\; (1212)^{i + 1}.
        \]
        Заменим его на произвольное слово $u$ из множества
        \[
        \begin{aligned}
        \{&12g_i34545312,\, 12g_i34545321,\, 
        12345453g_i12,\, 12345453g_i21,\\
        &12345g_i34512,\, 12345g_i34521,\, g_i\}.
        \end{aligned}
        \]
        
        \item Выберем произвольный фрагмент слова $g'$ 
        следующего вида:
        \[
            (1212)^i,\; g_i,\; (1212)^{i + 1},\; 
            g_{i + 1},\; (1212)^{i + 2}.
        \]
        Заменим его на произвольное слово $u$ из множества
        \[
            \{12g_1g_212,\, 12g_1g_221\}.
        \]
    \end{enumerate}

    Утверждение проверено посредством компьютерного перебора.

\section{Заключение}

В настоящей работе исследованы экстремальные свойства сборных чисел в классе простых сборных графов без петель. Основные результаты работы таковы.

\begin{enumerate}
    \item Доказана точная формула реализующего числа для графов без петель:
    \[
    \Romin(k)=5k-3.
    \]
    Нижняя оценка получена с помощью симметричного жадного алгоритма $\mathcal{G}_s$, совмещающего прямой и обращённый проходы, что позволило вывести неравенство $|\Gamma|\ge 5\An(\Gamma)-3$. Верхняя оценка предъявлена конструктивно — семейством $(1212)$-подстановок, которые дают примеры графов без петель со сборным числом $k$ и ровно $5k-3$ четырёхвалентными вершинами.
    
    \item Дана полная характеризация графов, на которых достигается равенство $|\Gamma|=5\An(\Gamma)-3$. Показано, что любой такой граф является $(1212)$-подстановкой. Тем самым установлен полный комбинаторный портрет экстремального случая $\D=0$.
    
    \item Для общего случая $|\Gamma| = 5\An(\Gamma)-3+\D$, $0\le \D\le 4$, предложена техника сведения к изучению семейства $\OPT_\D$, замкнутого относительно обращения и сохраняющего ключевые инварианты. С помощью этого подхода получено описание множества $\OPT_1$, путём компьютерного перебора паттернов, удовлетворяющих автоматным ограничениям. Результаты компьютерного моделирования подтвердили теоретические выводы и показали, что все такие графы строятся локальными заменами фрагментов $(1212)$-подстановки элементами явно выписанного конечного множества.
\end{enumerate}

Методологически работа объединяет теоретико-графовые и теоретико-языковые средства: жадные алгоритмы, анализ блоков рёбер, паттерны два-слов как правильные скобочные последовательности, регулярные выражения и пересечение недетерминированных конечных автоматов. Такое сочетание позволило получить точные количественные и структурные результаты там, где чисто комбинаторный перебор становится невозможным.

Дальнейшие направления исследований могут включать: завершение классификации графов без петель для оставшихся значений $\D=2,3,4$ с использованием предложенной техники пересечения автоматных языков; получение оценок реализующего числа для классов графов, не содержащих аналогов петель (подграфов, которые, в свою очередь, являются простыми сборными графами) размера два и больше — $w$-подстановки могут давать хорошие оценки сверху для таких семейств; а также исследование связи сборного числа с родом поверхности, в которую может быть вложен данный сборный граф, и перенос развитых методов на анализ топологических инвариантов.
