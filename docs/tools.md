## construct_set

Строит гамильтоново множество полигональных путей для заданного два-слова (см. ``./construct_set --help``).

Опция ``--algorithm`` позволяет выбрать алгоритм построения. Доступно три алгоритма:

1. Точный (``-a exact``).
2. Жадный (``-a greedy``).
3. Симметричный (``-a sym``). Выводит минимальное множество среди $Greedy(\Gamma)$ и $Greedy(\Gamma^{Rev})$.

Тул выводит следующую информацию:

1. Само разбиение на полигональные пути (первая строка).
2. Количество путей, рёбер и путей длины 0.

Пример использования:

```bash
./construct_set --algorithm exact 1,2,1,2,3,3
```

Весь функционал реализован в ``src/set_builders.cpp``.

## search_dow

Ищет все два-слова, удовлетворяющие нескольким требованиям (см. ``./search_dow --help``).

- Размер слова ``n``.

- Сборное число ``k``. Поддерживаются три вида ограничений: больше, меньше или равно константе.

- Паттерн два-слова ``p``. В паттерне могут встречаться только три символа: ``1``, ``2`` и ``?``. Первые два обозначают первое и второе вхождение какой-то буквы соответственно. Знак вопроса принимает как первое, так и второе вхождение.

- Минимальный допустимый размер собственного подотрезка два-слова ``m``, который, в свою очередь, является два-словом. При ``m = 1`` допускаются все два-слова. При ``m = 2`` запрещаются петли.

Тул выводит найденные слова списком в нормированном виде.

Пример использования:

```bash
./search_dow 7 =3
./search_dow -n 7 -k g1 --pattern 1122?1122?1122 --min-sub-word 2
./search_dow -n 7 -k l2 --pattern 11?11?12222??? --min-sub-word 7
```
