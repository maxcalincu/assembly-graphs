## construct_set

Строит гамильтоново множество полигональных путей для заданного два-слова (см. ``./construct_set --help``).

Опция ``--algorithm`` позволяет выбрать алгоритм построения. Доступно три алгоритма:

1. Точный (``-a exact``).
2. Жадный (``-a greedy``).
3. Симметричный (``-a sym``). Выводит минимальное множество среди $Greedy(\Gamma)$ и $Greedy(\Gamma^{Rev})$.

Тулза выводит следующую информацию:

1. Само разбиние на полигональные пути (первая строка).
2. Количество путей, ребер и путей длины 0.

Пример использования:

```bash
./construct_set --algorithm exact 1,2,1,2,3,3
```

Весь функционал реализован в ``src/set_builders.cpp``

## search_tw

Ищет все два-слова с заданным размером и сборным числом (см. ``./search_tw --help``).

Опция ``--exclude-loops`` исключает из пространства поиска все два-слова что содержат петли.

Тулза выводит все найденные слова списком. Слова предварительно отнормированы.

Пример использования (обе команды равносильны):

```bash
./search_tw --exclude-loops 8 2
./search_tw --exclude-loops -n 8 -k 2
```
